21 · ywzj 载具支持（NeoForge）

仅 1.21.1-NeoForge 分支：载具绑定网络、能量充电（FE/流体）、弹药补给、最大合成补料与 HUD

功能概述

为 ywzj 载具（org.ywzj.vehicle）提供维度网络接入：

  • 绑定——手持带网络 ID 的 BD 终端右键载具，网络 ID 写入载具 NBT（bce_net_id）
  • 能量充电——按配置从网络抽取能量（FE）或流体燃料为载具充电，支持固定速率 / 百分比模式
  • 弹药补给——载具武器装填时从网络提取配方所需的弹药物品
  • 最大合成补料——载具“一键最大合成”材料不足时从网络提取并放入背包
  • HUD——驾驶时在左下角（聊天栏图层下方）显示网络名称/ID、能量与当前武器弹药
分支说明ywzj 载具支持仅存在于 1.21.1-NeoForge 分支。1.20.1-Forge 分支未实现（该模组用户较少、更新不频繁），两分支除 ywzj 外的功能保持同步。

绑定流程

客户端手持 BD 终端右键载具VehicleNetMixin 拦截交互返回 SUCCESS
服务端读取终端网络 IDBDDataComponents.NET_ID_DATA
netId ≥ 0
写入绑定VehicleNetStorage.bindVehicle(uuid, netId) + NBT bce_net_id
通用兜底VehicleInteractHandler（EntityInteract 事件）处理其他载具并取消原交互
网络不存在或未绑定时 VehicleNetStorage.getBoundNetId 返回 -1，充电/同步逻辑直接跳过。

能量充电流程

每 tickAbstractVehicle.tick（服务端）
chargeMode=OFF / tickCount % chargeInterval != 0 → 跳过
缺口计算space = energyCapacity - getEnergy()
燃料来源fuelSource

FE

feNeeded = space × energyConversion
RATE：want = min(rate, feNeeded)
PERCENTAGE：want = ceil(feNeeded × pct%)
extract 能量 → addEnergy(实得 / conversion)

FLUID

遍历网络流体桶，按燃料白名单匹配（AllConfigs fuelNameWhiteList）
neededMb = space × 1000
extract 流体 → addEnergy(实得 / 1000)
损耗规避FE 路径对提取量按 energyConversion 向下取整后换算（避免余数损耗）；充电后 net.setDirty()。

弹药补给与合成流程

装填AbstractVehicleWeapon.reload
needed = maxCapacity - remainAmmo
按配方 Ingredient 逐项取弹storage.extract(ItemStackKey, 数量)
setRemainAmmo(remain + total)+ net.setDirty()
合成ClientMachineMaxAction.hasIngredients背包材料不足
findNetwork：主网络优先，回退菜单网络
从网络提取材料player.getInventory().add(...)
放行最大合成net.setDirty()

已知边界

① 客户端缓存清理YwzjVehicleCache.reset() 当前无调用点（无下车清理挂点），过期依赖 2 分钟 TTL。
② 绑定权限绑定阶段未校验玩家是否为网络成员（与其他载具绑定逻辑一致）。
③ 版本耦合Mixin 与 ywzj 载具内部结构强耦合，ywzj 更新后需回归验证。
