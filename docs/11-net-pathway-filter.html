28 · 维度网络通道（net_pathway）标记槽过滤

BD 网络通道的标记槽白名单过滤 + 方块配置保留（含破坏保留 / Shift+左键复制 / 清 NBT 配方）

功能概述

BD 的 net_pathway（维度网络通道）原本直接向邻居暴露网络的全部 UnifiedStorage。本功能给它附加标记槽白名单过滤：只有标记槽中的物品（精确资源）对外可见/可操作；标记为空则不暴露任何物品（严格白名单）。

  • 每方块开关：启用过滤 / 仅接收输入 / 模糊过滤（模糊 = 匹配时忽略 NBT/组件）。
  • 对外能力暴露按白名单裁剪；onlyInput 时邻居只能向网络插入、不能提取。
  • 全局配置 bd_tweaks.net_pathway_filter_rows（1~6，默认 3）→ 标记槽数 = 行数×9。

组件构成

组件职责
mixin/NetPathwayBlockEntityFilterMixin给 NetPathwayBlockEntity 挂标记槽与开关；getCapability 中按开关替换暴露的 UnifiedStorage
NetPathwayFilteredStorage白名单过滤的 UnifiedStorage 视图（getStackByKey/getOutStackByKey/insert/extract 受白名单与 onlyInput 限制）
mixin/NetedBlockEntityNetPathwayDataMixin持久化标记槽与开关（写入方块实体 NBT）
NetPathwayFilterMenu / NetPathwayFilterGUI过滤界面：复用 BD 原版布局（顶栏 + 过滤标记槽 FlagStackTypedSlot×行数×9 + 连接条 + 玩家背包），右侧为 BD RightTabButton 图标开关（启用过滤 / 仅接收输入 / 模糊过滤，QuickData 同步）
NetPathwayInteractionHandler交互：手持对应方块物品 Shift+左键 → 复制配置（并取消挖掘）；右键网络通道 → 打开过滤界面

未启用过滤 → 原样返回网络的 UnifiedStorage（行为与 BD 原版一致）；启用过滤但标记为空 → 白名单为空，邻居看不到任何物品。

方块配置保留（通用，覆盖所有 NetedBlock）

  • 破坏保留（bd_tweaks.neted_block_keep_nbt，默认开）：掉落物保留配置 NBT（标记槽 + 方块配置）。实现：NetedBlockKeepFilterNbtMixin 注入 Block.getDrops(BlockState, ServerLevel, BlockPos, BlockEntity)；剔除内容/计时/经验键，并写入 netId=-1，因此不保留网络绑定。
  • Shift+左键复制：手持与该方块对应的物品 Shift+左键点击方块 → 复制同样的配置到手上物品（同样不含网络绑定，并取消挖掘）；快捷栏上方显示 HUD 提示 hud.beyond_integration.net_copy_config。
  • 清 NBT 配方：为 8 种基础网络方块提供“自己合成自己”的无序配方（产出为干净物品，无配置 NBT）：net_pathway / net_interface / net_energy_pathway / net_terminal_block / net_pump_block / net_hopper_block / net_furnace_block / net_blast_furnace_block。
  • NetedBlockConfigNbt：统一提取“仅配置”的 NBT（破坏/复制共用）。

配置项（bd_tweaks）

键默认说明
net_pathway_filter_rows3网络通道标记槽行数（1~6，全局；标记槽 = 行数×9）
neted_block_keep_nbttrue维度网络方块破坏时保留配置 NBT（不含网络绑定/内容/进度）
过滤开关为每方块设置（存入方块实体 NBT，随 QuickData 同步），非全局配置。
