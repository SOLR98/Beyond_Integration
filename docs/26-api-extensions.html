20 · API 与扩展点

api 包公开接口、女仆网络 API、BD GUI 扩展注册表与统一订阅中心

功能概述

面向其他模组（以及未来扩展）的公开接入层，位于 com.solr98.beyondintegration.api 与核心工具包：

  • 整合接口——按 modId 条件注册的通用集成单元（IModIntegration）
  • 业务扩展点——合成集成（ICraftingIntegration）、网络弹药提供（INetworkAmmoProvider）、载具能量系统（IVehicleEnergySystem）、插入前扩展（IBeforeInsertExtension）
  • BD GUI 扩展——IDimensionsNetGUIExtension + 注册表 BDGUIExtensionRegistry
  • 女仆网络 API——MaidNetworkAPI（Maid_Net_Storage 等附属模组直接编译依赖）
  • 订阅中心——core/subscribe/BdSubscriptionHub 统一封装 BD 存储订阅
依赖方向这些 API 均为“BI 对外暴露”，BI 自身不反向依赖调用方；除女仆 API 外，其余接口在当前仓库内暂无实现方，属于预留扩展点。

女仆网络 API（MaidNetworkAPI）

供 Maid_Net_Storage 等附属模组直接调用的门面类。所有方法对“未安装女仆/BD、实体非女仆、无网络、客户端侧”安全（返回 null / -1 / 0 / false / 空集合），弹药与物品操作仅应在服务端主线程调用。

GUI 扩展注册流程

实现扩展implements IDimensionsNetGUIExtension
注册BDGUIExtensionRegistry.register(extension)
按 priority 降序排列
客户端BD GUI 生命周期回调onInit / onRender / onMouseClicked
消费与否onMouseClicked 返回 true 则中断后续扩展
相关实现StorageMenuExtension（存储界面聚合扩展）、ItemProtectExtension（Ctrl+右键切换保护标记）、AmmoPanelExtension（SW 弹药面板，Forge）。

统一订阅中心（BdSubscriptionHub）

能力说明
统一入口对 BD 存储的 delta / any 订阅统一经 Hub 注册，避免各处直接调用 BD API
owner 注册表按 owner 维护订阅，重复订阅自动替换，GC 惰性清理弱引用
批量退订网络销毁 / 服务器停止时按网络批量退订
失败记录订阅失败记录 WARN 日志
BI 内部弹药追踪器（SwAmmoTracker / TaczAmmoTracker）、载具缓存等均经 Hub 订阅，不直接调用 BD 订阅 API。
