07 · 哨戒机械臂联动（Create Sentry Mechanical Arm）

哨戒臂绑定维度网络作为弹药来源，装填直取网络弹药，假玩家同步携带网络终端

功能概述

Create 哨戒机械臂（SentryMechanicalArm）原本只使用其自带的弹药箱（attachedAmmoBoxes）供弹。本模组让哨戒臂可绑定一个维度网络作为弹药来源：

  • 右键绑定/装填——手持带网络 ID 的物品右键哨戒底座：物品存入弹药箱并写入网络 ID
  • 装弹注入——哨戒臂装弹（performInstantReload）时从绑定网络直取弹药
  • 假玩家携带终端——装填前把网络 ID 伪装成 NetedItem 塞入哨戒臂 FakePlayer 第 9 格，使枪械弹药判定（TACZ/SW 的背包扫描）能感知网络
  • 持久化——网络 ID 随方块实体 NBT 读写（键 beyond$netId），重启不丢失

绑定流程（右键）

客户端手持联网物品右键哨戒底座SentryArmBlock.use 注入 HEAD
服务端读取物品网络 IDNetedItem.getNetId(stack)
物品为空或 netId < 0 → 原版交互
探测方块实体反射 getHeldItem()（无枪提示 sentry_no_gun）
有枪
加入弹药箱反射 addAmmoBox(stack) → 成功后 setSentryNetId(netId)
消耗与提示非创造模式物品 -1；sentry_net_bound 提示；取消原版交互
已知边界反射调用失败被静默捕获（catch Exception ignored），哨戒臂版本不匹配时玩家右键无反馈；绑定未校验玩家是否为该网络成员。

装弹 / 射击供弹流程

哨戒臂逻辑performInstantReload（装弹）@Inject HEAD
SentryArmReloadMixin读 beyond$netId → 绑定网络
网络有弹
从网络直取弹药（单次上限 9000）
装弹完成原逻辑继续射击
射击判定哨戒臂 FakePlayer 背包 → SentryFakePlayerSyncMixin 已塞入伪 NetedItem
枪械弹药扫描TACZ AbstractGunItem / SW AmmoConsumer 的背包扫描感知网络
从网络扣弹（复用文档 13/14 的扣弹链路）
假玩家细节伪 NetedItem 放在第 9 格（哨戒臂自身用 9+i 槽放弹药箱，无冲突）；换枪路径会 clearContent() 清空背包，需在下次装填时重新写入。
