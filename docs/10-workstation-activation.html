24 · 工作台献祭激活（可选平衡项）

使用工作台前需献祭对应原版工作台激活（网络级，一次激活全网络可用）· 合成台与 BD 终端不参与

功能概述

开启后，除合成台（craft）与 BD 终端（storage）外的工作台需先献祭对应原版工作台物品激活：

工作台默认献祭成本
铁砧 anvil1 × 铁砧
切石机 cut1 × 切石机
砂轮 grind1 × 砂轮
锻造台 smith1 × 锻造台
附魔台 enchant1 × 附魔台
  • 激活状态为网络级：一次激活后该网络所有成员可用，随存档持久化。
  • 未激活的工作台模式按钮显示禁用纹理 + 锁定 tooltip；点击 = 献祭激活（从网络存储扣除献祭物品），不再打开工作台。
  • 服务端权威校验：未激活时打开工作台请求被拒绝并提示（防绕过）。
  • 启用列表随同步包下发：右侧工作站按钮的显示与配置界面（禁用标记、拖拽排序）使用服务端下发的 workstations.enabled 权威列表（打开网络界面时请求、激活成功时推送；未同步前回退本地 common 配置）。
可选平衡项默认关闭（enable=false），不开启时与常规行为完全一致。

组件构成

组件类职责
激活逻辑feature/workstation/WorkstationActivation可激活判定、献祭扣除（不足自动回滚）、重置、成本解析
网络数据NetworkAmmoData（workstationActivation 段）按网络持久化已激活工作台集合（BI 自有存档数据，不写 BD 网络 NBT）
访问接口handler/WorkstationActivationAccessor（实现于 DimensionsNetMixin）网络级查询 / 激活 / 重置
网络包ActivateWorkstationPacket / RequestWorkstationActivationPacket / WorkstationActivationSyncPacket（Neo：network/payload/）激活请求 / 状态查询 / 状态下发（献祭开关 + 已激活集合 + 服务端启用列表）
客户端状态client/WorkstationActivationCache开关 + 已激活集合 + 服务端启用列表（供按钮锁定显示、按钮可见集与配置界面判定；进服/登出重置）
打开校验OpenStorageMenuPacket（Neo：OpenStorageMenuPayload）未激活拒绝打开并提示
管理命令command/network/NetworkWorkstationCommand重置（单独/全部）；激活状态查看并入 network info

流程

① 献祭激活

客户端点击未激活的工作台按钮发送 ActivateWorkstationPacket
服务端校验开关 / 工作台 ID / 主网络 / 是否已激活
成本未配置 → 直接激活
从网络扣除献祭物品extract（不足时回滚已提取部分）
写入网络数据WorkstationActivationAccessor.activate + markDirty
状态下发Sync 包 → 客户端缓存 → 按钮解锁

② 打开校验（服务端兜底）

点击已激活按钮OpenStorageMenu 请求
开关启用且未激活？
是 → 拒绝 + 提示“需献祭 XXX”
正常打开工作台菜单

配置与命令

项值 / 用法
workstations.activation.enable总开关（默认 false）
workstations.activation.costs献祭成本（格式 工作台ID:物品ID:数量；未列出的工作台无需献祭）
重置命令/bdtools network workstation reset <工作台ID|all> [netId]（OP；ID 带 Tab 补全）
状态查看/bdtools network info 输出“已激活工作台：…”行（仅开关启用时显示）
图形配置Cloth Config 界面「工作台」分类：献祭激活开关 + 成本列表；「客户端」分类的工作站顺序列表会隐藏服务端已禁用项
