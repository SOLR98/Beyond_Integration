## 填法

在"你的决定"列填四选一：

| 值 | 含义 |
|---|---|
| `module` | 独立模块 `modules/<id>/` |
| `inline:<父>` | 内置到父模块的 `enhance/<id>/`，例如 `inline:tacz` |
| `lib` | 只进 `libs.versions.toml`，不建模块（前置库、运行时、无关） |
| `none` | 从依赖里删掉（没有代码引用、也不是运行时需要） |

留空 = 尚未决定，构建会报"未归类"。

## 落地后的形态

```toml
# modules.toml（放在仓库根，人工维护）
[tacz]
type = "module"

[taczaddon]
type = "inline"
parent = "tacz"

[jei]
type = "module"

[curios]
type = "lib"

[quark]
type = "none"
```

三条校验（CI）：

1. `libs.versions.toml` 里每个 `curse.maven:*` / `maven.modrinth:*` 都必须在 `modules.toml` 出现，否则报"未归类"；
2. `inline` 的 parent 必须是 `type = "module"`；
3. `type = "none"` 的坐标不得出现在任何 `module.gradle` 里。
