33 · 通用 HUD 布局框架

可自定义各 HUD 位置（保存为屏幕比例，缩放窗口后按比例跟随）· 单界面同屏拖动编辑 · 统一配置 hud_layout · 仅客户端

一、目标

把「BI 自有 HUD 的位置」做成可配置 + 可视化调整的通用设施：

  • 每个 HUD 元素有默认位置（相对原版锚点或固定）；
  • 编辑器保存为当前屏幕比例（RATIO），窗口/分辨率缩小后仍按相对位置显示；旧版相对偏移/绝对坐标仍可读取；
  • 用同一个编辑器界面同屏展示所有可调 HUD，拖动即所见即所得；
  • 布局统一存于一份客户端配置 hud_layout（合并管理）。
一句话新增 HUD 只需「加枚举 + 注册预览 + 绘制处取坐标」三步即可纳入统一位置框架。

二、组件

组件类职责
元素枚举client/hud/HudElement可调 HUD 的 ID 与显示名（soul / net_sync / net_mana）
布局client/hud/HudLayout解析/写入 hud_layout；resolveX/Y(e, defX/Y, screenW/H) 求实际坐标；setRatio/setAbsolute/clear
预览接口client/hud/HudPreview元素的命中尺寸、默认位置、预览绘制、可用性（依赖模组缺失时从编辑器隐藏）
注册表client/hud/BiHudsHudElement → HudPreview 注册与枚举
编辑器client/gui/HudPositionScreen同屏展示全部元素；点击选中、拖动移动；保存为屏幕比例/重置；按钮避让当前项
条体渲染client/render/SoulHudRendererSOUL 元素的 HUD 与预览共用渲染

三、配置（CLIENT）

键默认说明
hud_layout空统一布局列表。编辑器写入 <id>=RATIO:x:y（x/y 为 0..10000 的屏幕万分比）；兼容读取旧的 <id>=RELATIVE:dx:dy / <id>=ABSOLUTE:x:y；无项 = 该 HUD 默认位置。
show_net_sync_statusfalse是否显示主网络同步状态 HUD（仅同步启用时生效）。
irons_mana_hudtrue是否显示网络魔力独立 HUD（需铁魔法与网络魔力源）。
hud_visual_edittrue是否允许用快捷键打开位置编辑器。
快捷键「打开 HUD 位置调整」（key.beyond_integration.open_soul_hud_editor，默认未绑定，控制设置中分配）。

四、位置语义

  • RATIO（编辑器保存）：实际坐标 = 万分比 × 当前屏幕尺寸；窗口/分辨率变化后按比例跟随（如 5000 = 屏幕中线）。
  • RELATIVE（旧格式，兼容读取）：实际坐标 = 元素默认坐标 + (dx,dy)。默认坐标由元素自身决定（如 SOUL 为「原版灵魂条上方两行」、NET_SYNC 为「快捷栏上方水平居中」）。
  • ABSOLUTE（旧格式，兼容读取）：实际坐标 = (x,y)（GUI 缩放坐标，元素左上角）。
  • 无 hud_layout 项：直接用元素默认坐标（行为与未引入本框架一致）。
  • 容错：格式错误、未知模式、越界比例（RATIO 超出 0..10000）或解析异常时，该元素自动回退默认位置，不会崩溃；保存时会顺带清理同 id 的损坏项。

id名称默认位置备注

六、扩展新 HUD（三步）

  1. 在 HudElement 加枚举项（含 id）；
  2. 在 BiHuds 静态块 register(...) 其 HudPreview（width()/height()/render()/defaultX()/defaultY()）；
  3. 该 HUD 的绘制处把最终坐标改为 HudLayout.resolveX(元素, defX) / resolveY(元素, defY)。
随后该 HUD 会自动出现在编辑器中并可独立保存；无需改动编辑器或配置结构。

七、编辑界面行为

  • 同屏渲染所有已注册元素：当前选中项橙色描边、其余半透明描边；
  • 点击任一元素即选中并开始拖动；◀ / ▶ 循环切换选中项；
  • 保存：把选中项按当前屏幕尺寸写为 RATIO 比例（窗口缩放后按比例跟随）；重置：清除该项回默认；
  • 屏幕中心十字为参考线；顶部显示当前元素名、x/y 与模式；
  • 保存/重置按钮自动避让当前正在调整的元素（默认底部，重叠则切顶部，两端都叠取重叠更小的一侧）。
