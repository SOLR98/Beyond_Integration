19 · 经验棒增强（bd_tweaks）

解除 BD 经验棒目标等级上限、分批发放与直设式发放（网络经验优先）

功能概述

BD 的经验棒（beyonddimensions:xp_exchange_item）“保留目标等级”模式原版存在 21863 级上限，且一次发放巨量经验会触发经验条异常。本模组提供 bd_tweaks 三项增强：

  • 等级上限提升——目标等级上限改为配置值（默认 238609312，即原版升级成本公式在 int 范围内不溢出的最高等级）
  • BATCH 分批发放——把一次大额经验拆成每 tick 一批（批次大小可配），避免经验条跳变异常
  • DIRECT 直设式发放——不从升级公式走，直接反解等级并设定等级/进度，网络经验流体不足时补差
开关层级bd_tweaks.xp_rod_enabled 为总开关，关闭后完全回退 BD 原行为；BATCH / DIRECT 通过 bd_tweaks.grant_mode 二选一。

组件构成

组件类职责
分批发放handler/XpGrantHelper每 tick 批次上限、等级空间计算（BATCH_MAX_LEVEL）
直设发放handler/XpDirectGranter网络经验提取、等级反解、字段直设

BATCH 分批发放流程

服务端经验棒 keep 模式计算本次发放量XpUtil.clampXpToGive
XpGrantHelper.pendingPerTick校验等级/总经验/进度
levelRoom = xpToReachAtLeast(当前, min(配置上限, BATCH_MAX_LEVEL))
批次额度min(grant_batch_size, 请求量)
batch_size ≤ 0 → 一次性发放
本 tick 发放一批剩余量进入下一 tick
BATCH_MAX_LEVEL = 238609312再往上升级所需经验超过 int 上限（经验条会异常），因此分批模式的上限受此硬约束；更高的目标等级请使用 DIRECT 模式。

DIRECT 直设式发放流程

服务端XpExchangeItem.keepXpLevel（HEAD 注入）
XpDirectGranter.tryGrant请求量 ≤ 0 → 回退 BD 原逻辑
提取网络经验优先 xpFluidKey()，不足再遍历经验流体
按 getConversionRate() 换算（1 点 = 20 mB）
计算新总经验levelAsDouble / xpBetweenLevels
二分反解 levelForTotalXp
直设字段experienceLevel / experienceProgress；totalExperience 按 int 钳制
经验零头回插网络
完成不经过原版升级公式

配置项（bd_tweaks 分区）

配置默认说明
xp_rod_enabledtrue经验棒修改总开关
max_target_level238609312可设定目标等级上限（0–Integer.MAX_VALUE）
grant_batch_sizeInteger.MAX_VALUE-1每 tick 发放批次上限（0 = 不分批）
grant_modeBATCHBATCH 分批 / DIRECT 直设式
furnace_terminal_smelt_allfalse终端熔炼开关（见文档 08）

已知边界

① 经验总量 int 限制玩家 totalExperience 为 int 字段，超过 Integer.MAX_VALUE 后仅等级与进度可继续增长，统计/展示口径可能与实际不符。
② 绕过升级回调DIRECT 模式直接设定等级字段，不触发原版逐级升级逻辑（统计数据与部分事件不会产生）。
③ 依赖 BD 内部实现三项注入均 @Shadow/直读 BD 内部字段，BD 大版本更新后需回归验证。
