15 · 网络附魔台

不依赖书架的远程附魔台：功率取自网络 XP / 玩家等级 / 固定值，支持悬停预览、刷新、宽松选魔与解限

功能概述

网络附魔台是 0.6.5 新增的第 7 种远程工作站。它不读取书架，而是按配置从三种来源计算附魔功率（等价书架数量）：

  • FIXED——固定功率（默认 15，解限后最高 100）
  • NETWORK_XP——按网络内经验流体存量换算
  • PLAYER_LEVEL——按玩家经验等级换算

在此之上提供一组可开关的增强：悬停预览三槽将获得的附魔（含升级标记）、刷新候选（消耗燃料）、允许反复附魔（ignoreEnchanted）、允许冲突附魔（ignoreConflict）、免燃料（noLapis）、解除等级门槛改为经验点计费（levelGateIgnore）、功率解限（uncapPower）、费用百分比缩放（costPercent）、允许宝藏附魔（allowTreasure）。

燃料免手动打开界面时自动从主网络补足附魔燃料（青金石等 Tags.Items.ENCHANTING_FUELS）至 64；关闭/清空时剩余燃料按归还方向存入网络。

打开与功率计算流程

客户端快捷键 / 网络 GUI 工作站按钮发送打开请求
服务端校验 workstations.enabled + 主网络
服务端创建菜单beyond$autoFillFuel() 从网络补燃料至 64
功率来源beyond$power()
FIXEDenchantFixedPower（默认 15）
NETWORK_XP网络 XP 流体 / xpPerPower
PLAYER_LEVELexperienceLevel / levelPerPower
功率上限默认封顶 15（等价 15 书架）；开启 uncapPower 后上限 100，此时费用公式改用内部实现 beyond$vanillaCost（原版公式在高功率下需要替代算法）。

候选生成与预览流程

服务端物品/燃料槽变化seed = enchantmentSeed + refreshTick
费用计算EnchantmentHelper.getEnchantmentCost（高功率用 beyond$vanillaCost）
等级事件onEnchantmentLevelSet（允许其他模组改写）
选魔路径ignoreEnchanted ?
标准EnchantmentHelper.selectEnchantment（enchantAllowTreasure 并入 TREASURE）
宽松beyond$selectLoose：已附魔仅接受更高等级；新附魔冲突需 ignoreConflict
S2CEnchantCluesPacket下发三槽候选（服务端 previewEnabled 关闭时发空表）
客户端previewCache 渲染悬停显示完整列表；升级条目追加金色“将升级”标记

附魔执行与计费

客户端点击三费用按钮之一handleInventoryButtonClick
双端校验：noLapis / levelGateIgnore / costs[id] / 物品非空
服务端beyond$doEnchant按费用缩放 costPercent
计费方式levelGateIgnore ?
等级制（默认）onEnchantmentPerformed：扣玩家等级 + 燃料
点数制beyond$chargePoints：网络 XP 流体优先（1 点 = 20 mB），不足扣玩家经验点
施加附魔applyEnchantments（书 → 附魔书）+ onPlayerEnchantItem
收尾扣燃料、统计、ENCHANTED_ITEM 触发器、seed 更新、音效
点数不足提示 gui.beyond_integration.enchant.need_xp_points 并中止本次附魔（不扣料）。

刷新流程

客户端点击刷新按钮EnchantIconBtn（时钟图标；物品槽为空或服务端关闭时隐藏）
C2SRefreshEnchantPacket(containerId)
服务端doRefresh校验 refreshEnabled → 扣 refreshLapis 燃料 → refreshTick++
slotsChanged + broadcastChanges
三槽重掷并重新下发预览

配置项（enchant_table 分区）

配置默认说明
powerModeFIXED功率来源：FIXED / NETWORK_XP / PLAYER_LEVEL
fixedPower15FIXED 模式功率（0–100）
xpPerPower100NETWORK_XP 模式每 1 功率消耗的经验点（1 点 = 20 mB 流体）
levelPerPower1PLAYER_LEVEL 模式每 1 功率消耗的玩家等级
ignoreEnchantedfalse已附魔物品可继续附魔/升级（宽松选魔）
ignoreConflictfalse允许附上冲突附魔
noLapisfalse免燃料附魔
levelGateIgnorefalse解除等级门槛，改为经验点计费（网络 XP 优先）
uncapPowerfalse功率上限 15 → 100
costPercent100费用缩放百分比（10–500）
allowTreasurefalse允许宝藏附魔
previewEnabledtrue服务端开关：悬停预览下发
refreshEnabledtrue服务端开关：刷新按钮
refreshLapis1每次刷新消耗燃料数（0 = 免费）
NeoForge 额外（神化模式）
apothQuanta / apothArcana15 / 0神化附魔属性（etra 取功率值）
客户端偏好悬停预览受客户端配置 enchant_preview_on 与服务端 previewEnabled 共同控制（两者都开才显示）。

NeoForge 神化（Apotheosis）模式现状

已实现DimensionsApothEnchantMenu三属性 DataSlot / ApothEnchantmentHelper 费用与选魔 / 经验点计费
DimensionsEnchantApothGUI属性条渲染 / 符石候选 tooltip
入口暂未启用
当前固定走原版模式打开逻辑中的神化分支与模式切换按钮被 TODO 注释，即使客户端偏好为神化也不生效
已知边界① 预览列表仅在重算时下发，快速连续操作时客户端短时显示旧候选；② 宽松选魔的随机分布与原版不完全一致；③ beyond$chargePoints 以玩家 totalExperience 判断余额，极端等级/点数换算下与视觉经验条可能有偏差。
