11 · /bdtools 命令系统

维度网络管理命令树、权限模型、中英双语输出

功能概述

/bdtools 是管理 Beyond Dimensions 网络的管理命令集，覆盖：网络查询 / 批量创建 / 资源生成 / 终端发放 / 成员与经理权限管理 / 跨玩家远程打开 GUI / 批量附魔分离。输出支持中英双语（服务端翻译）与 SI 单位数字格式化（K/M/G/T/P/E）。

命令树

/bdtools                          （根命令，需 OP 2 级）
├── network
│   ├── list                      列出所有网络（含成员/经理/状态，分页）
│   ├── info [netId|玩家]          查看网络详情（容量/资源统计）；参数可为网络 ID 或玩家名（查其主网络）
│   ├── insert item <物品> [数量] [netId]     向网络插入物品
│   ├── insert tag <#标签> [每种数量] [netId]  按物品标签批量插入（逐种列表输出，空间不足自动跳过）
│   ├── insert fluid <流体> [mB] [netId]      向网络插入流体
│   ├── insert energy <FE数量> [netId]        向网络插入能量（数量在前、网络 ID 在后）
│   ├── workstation reset <工作台ID|all> [netId] 重置工作台献祭激活（单独/全部；ID 带 Tab 补全）
│   ├── generateResources <netId> 生成网络资源（合成产物）
│   ├── giveTerminal <player>     发放网络终端物品
│   ├── giveEnchantedBooks <player> 发放附魔书
│   └── batchCreate <player> <count> 批量创建网络
├── member
│   ├── addMembers <netId> <players>    添加成员
│   ├── addManagers <netId> <players>  添加经理
│   ├── removePlayers <netId> <players> 移除成员
│   └── removeManagers <netId> <players> 移除经理
├── myNetworks                   查看自己的网络（分页）
├── open <player>                打开网络 GUI
├── openAny <netId>              无视权限打开任意网络（查水表）
└── enchant
    └── separate [netId]          批量附魔分离
工作台激活状态开关启用时 network info 会输出“已激活工作台：…”行（详见文档 10）。
完整链路文档见 1.20.1-FORGE/COMMAND_CHAIN.md（命令树、中英双语消息表、分页/按钮辅助文本）。

命令执行流程

注册期RegisterCommandsEventBDNetworkCommands 构建命令树（建议与执行层）
执行期命令执行CommandUtils 解析参数 / NetworkUtils 取网络
PermissionChecker 权限校验
OP 级checkOpPermission 源命令（server/owner）
网络级owner → addManager 类操作
网络级owner/manager → 成员管理
成员级member → 只读/自身网络操作
执行 BD 操作创建/插入/遍历（最多 10000 网络 ID 扫描）
OutputFormatter格式化数字（K/M/G/T/P/E）
CommandLang 双语输出成功/失败消息

权限模型

权限类校验点说明
OP 2 级PermissionChecker.checkOpPermission网络管理类命令（list/info/insert/generateResources/giveTerminal/batchCreate/openAny）
Owner-onlycheckAddManagerPermission添加/移除经理（当前 addManagers/removeManagers 实际使用 owner-or-manager 检查，见风险）
Owner/ManagercheckNetworkManagementPermission成员增删、enchant separate
MemberNetworkPermission 枚举myNetworks / open 自身网络
已知问题（待修复）① addManagers / removeManagers 未使用 owner-only 检查——经理可横向提升权限；② /bdtools enchant separate 无 requires 权限门槛。
