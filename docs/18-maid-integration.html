09 · 女仆联动（Touhou Little Maid）

女仆佩戴 BD 网络终端作为饰物，射击消耗网络弹药、装备自动充能、死亡网络图腾救援

功能概述

Touhou Little Maid 的女仆通过「饰品槽」佩戴物品获得行为。本模组把 BD 的便携网络终端（beyonddimensions:net_terminal_item）注册为女仆饰物：

  • 女仆饰品槽 / 专用饰物栏放入网络终端 → 女仆获得网络访问能力
  • 女仆持枪射击时（TACZ / SW），若网络中有对应弹药则消耗网络虚拟弹药而非背包弹药
  • 女仆佩戴的装备/饰物按 energy_ammo 配置从网络自动充能（可关闭）
  • 女仆死亡时从网络自动消耗不死图腾救援

网络定位经 MaidNetworkCache 缓存（5 秒刷新），减少饰品栏扫描开销；女仆移除时清理缓存。

能力边界BI 只提供女仆的「网络基础对接」；女仆玩法层（任务需求取物、餐厅/厨房等）由附属模组 Maid_Net_Storage 承担，详见仓库根目录《女仆相关能力边界》。

饰品注册流程（模组加载期）

女仆模组扫描AnnotatedInstanceUtil扫描全部模组的 @LittleMaidExtension 注解类
实例化MaidBaubleExtension（implements ILittleMaid，无参构造）
BaubleManager.init()遍历 EXTENSIONS → bindMaidBauble(manager)
绑定查找 beyonddimensions:net_terminal_item → manager.bind(terminal, 空饰物实现)
完成终端物品在女仆饰品槽可放入

女仆射击扣弹流程

射击AmmoConsumer.consume（shooter = 女仆实体）
查缓存MaidNetworkCache（女仆 UUID → 网络 ID，超 5 秒则重新扫描）
缓存 miss → MaidNetworkHelper 扫描饰品槽
绑定网络弹药（TACZ ammoId / SW 类型）
有弹
扣网络虚拟弹药net.setDirty()
完成（无网络/无弹 → 回落原背包逻辑）
已知边界MaidNetworkCache 为普通 HashMap（仅服务端线程访问，安全），但清理依赖 MaidCacheCleanupMixin 注入点——若注入失效则缓存缓慢增长。
