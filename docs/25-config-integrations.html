COMMON + CLIENT 两份配置、多语言注释、JEI / Jade / Cloth Config 集成、可选模组共存

配置系统

0.6.x 起配置分为两份文件：

文件类型内容
beyond_integration-common.tomlCOMMON（CommandConfig.SERVER_SPEC）服务器逻辑：语言、计费、开关、阈值等 16 个分区
beyond_integration-client.tomlCLIENT（ClientConfig.CLIENT_SPEC）客户端 UI 偏好：枪械台模式、归还方向、附魔预览、工作站顺序

已知问题COMMON 类型在 Forge 中双端各读各的文件——专服下客户端与服务端的黑名单/计费设置可能不一致（仅 SERVER 类型会随连接同步）； 工作站启用列表已通过 WorkstationActivationSyncPacket 单独下发，客户端按钮与配置界面使用服务端权威值。
多语言注释core/config/ConfigCommentLang 从 lang 文件读取 beyond_integration.config.comment.*，加载完成后按语言重写配置注释（FMLLoadCompleteEvent → saveIfLanguageChanged）。

Cloth Config 图形界面

客户端ModConfigScreen注册 IConfigScreenFactory（若 cloth_config 加载）
游戏内配置界面分组编辑全部配置项（含「FTB 任务集成」「网络图腾」等分类）； 工作站顺序为可拖拽列表（DraggableModeListEntry，按服务端下发列表隐藏禁用项并标记）
保存生效（无 cloth 时优雅回退为手动编辑 toml）
