05 · 附魔分离器

多附魔书入网自动拆分，消耗网络 XP 流体与普通书，费用公式可配置

功能概述

物品进入维度网络时，若网络开启了「附魔分离」，系统自动把多附魔书拆分为多本单附魔书（每附魔一本），并消耗网络中的 XP 流体（BD 经验液）与普通书，费用按可配置公式/规则计算。

  • 自动触发：任何方式把多附魔书输入网络（插入拦截链）
  • 手动触发：/bdtools enchant separate [netId] 扫描全网络批量分离
  • 物品保护：带 beyond_integration:protect_sep 标记的物品跳过分离（GUI Ctrl+右键切换，见文档 09 同款保护机制）
范围说明0.6.x 起自动分离仅处理多附魔书（附魔物品剥离不再自动执行）；开关位于网络 GUI 左侧按钮（EnchantToggleBtn），状态由 NetworkAmmoData 按网络持久化。
同类同级自动合并（默认关闭，merge_same_level）单附魔书入网时，若网络内已有同附魔且同等级的单附魔书，则二者合并为 L+1 级：消耗网络那本与输入书，并按铁砧合并费用（等级 → 0→费用等级总经验点，20 mB/点）扣网络 XP；经验不足则原书正常入库。产出的高一级书插回网络时会再次经过拦截链，从而自然级联；达到附魔等级上限（含 Apotheosis 上限）时停止。

费用规则

# 每附魔费用（默认规则）
(base_cost + (level - 1) × level_multiplier) × 附魔倍率
# 附魔倍率：high_cost_list 指定的附魔用其倍率，其余用 default_multiplier
# 可选自定义公式（use_formula = true 时生效，cost_formula 字符串）：
base + (level - 1) * multiplier
# 支持变量：base / level / multiplier / books
配置默认说明
enablefalse附魔分离总开关（默认关闭；网络级开关初始也为关闭，可在 BD 界面左侧按钮开启）
base_cost10每附魔基础经验消耗（0–1000）
level_multiplier5每级额外经验消耗（0–100）
default_multiplier1.0默认费用倍率（0.1–10.0）
high_cost_list["minecraft:mending:3.0","minecraft:sharpness:1.2"]按附魔指定倍率，格式 modid:id:倍率
use_formulafalse启用自定义公式
cost_formula"base + (level - 1) * multiplier"公式字符串（变量 base/level/multiplier/books）
debugfalse输出 [enchant-sep] 调试日志
merge_same_levelfalse单附魔书同类同级自动合并（两本 L 级 → 一本 L+1 级，铁砧费用转网络经验；开启后自动级联）
已知边界附魔等级为负数/0 时（NBT 可构造）费用可为负，绕过部分费用检查；separateAll 已先扣原书并校验 extract 返回值（不足则跳过），不再只产出不扣书。
