30 · BD 贴图使用指南

Beyond Dimensions（beyonddimensions）贴图资源目录、命名规范、引用方式与可复用 GUI 部件 · 基于 BD 0.7.30 源码（1.20.1-FORGE 与 1.21.1_NEOFORGE 两分支同名）· 供 BI 及附属模组复用

总述

  • BD 贴图命名空间为 beyonddimensions，根目录 assets/beyonddimensions/textures/。
  • 分三大目录：block/（方块）、item/（物品）、gui/（界面）。
  • 引用分两种路径：**普通纹理（完整路径 + blit）** 与 **GUI 精灵（短名 + blitSprite）**。
  • BI 复用 BD 界面风格时，统一复用其 slot_button 系列、箭头、模式图标与面板底图，避免自制贴图风格不一致。

目录结构

目录内容规模（0.7.30）
textures/block/方块贴图（net_pathway.png、net_furnace_front.png、mana_pool_* 等）27 个文件（含 .mcmeta 动画）
textures/item/物品贴图（net_terminal_item.png、xp_exchange_item.png、net_magnet_item.png 等）20 个文件
textures/gui/面板底图、槽位行、连接条、标签页等（完整路径引用）18 个文件
textures/gui/sprites/widget/按钮 / 图标 / 模式精灵（短名引用）64 个文件
带 .png.mcmeta 的贴图为动态贴图（如 net_pathway、net_creater、unstable_space_time_fragment），引用方式与静态贴图一致。

引用方式

1 · 普通纹理：完整路径 + blit

// 完整路径包含 textures/ 前缀与 .png 后缀
private static final ResourceLocation BG = ResourceLocation.parse(
        "beyonddimensions:textures/gui/top_base.png");

// blit(纹理, x, y, u, v, w, h, 纹理宽, 纹理高)
guiGraphics.blit(BG, leftPos, topPos, 0, 0, 176, 24, 256, 256);

用于面板底图、槽位行、连接条等非精灵贴图。BI 亦可用此方式引用 BD 精灵（见下）。

2 · GUI 精灵：短名 + blitSprite

文件放在 assets/<ns>/textures/gui/sprites/<path>.png，引用时省略 textures/gui/sprites/ 前缀与 .png，写作 <ns>:<path>：

// 文件：assets/beyonddimensions/textures/gui/sprites/widget/right_tab.png
private static final ResourceLocation RIGHT_TAB = ResourceLocation.parse(
        "beyonddimensions:widget/right_tab");

// blitSprite(精灵, x, y, w, h)
guiGraphics.blitSprite(RIGHT_TAB, leftPos, y, 26, 12);

// 等价短写法（BD 内部常用）
ResourceLocation.tryBuild("beyonddimensions", "widget/up_arrow");

3 · 三态按钮：WidgetSprites

WidgetSprites bg = new WidgetSprites(
        ResourceLocation.tryBuild("beyonddimensions", "widget/slot_button"),
        ResourceLocation.tryBuild("beyonddimensions", "widget/slot_button_disabled"),
        ResourceLocation.tryBuild("beyonddimensions", "widget/slot_button_hovered"));

// get(是否可用, 是否悬停) → 选中对应态精灵
guiGraphics.blitSprite(bg.get(this.active, this.isHoveredOrFocused()), x, y, w, h);
两种写法等价：同一精灵既可 blitSprite("beyonddimensions:widget/slot_button", …)，也可 blit("beyonddimensions:textures/gui/sprites/widget/slot_button.png", …)。BI 多用完整路径 + blit 以保持 1.20.1 / 1.21.1 双分支一致（BI 侧示例见文末）。

命名与存放规范

  • 小写蛇形（snake_case）命名，语义前缀 + 变体后缀：slot_button_hovered、feeder_mode_normal、hopper_nbt_mode_deny。
  • 三态/多态用后缀区分：_hovered / _disabled / _allow|_deny / 档位名。
  • 可复用部件放 textures/gui/sprites/widget/（走精灵系统）；整块面板底图放 textures/gui/（走完整路径）。
  • 新增贴图不建议改动 BD 现有文件；BI 自有贴图放 assets/beyond_integration/…，需要 BD 风格时直接引用 BD 贴图。

BI 复用示例

完整路径 + blit（BI 默认写法，双分支一致）

// beyond_integration 侧：复用 BD 槽位按钮
private static final ResourceLocation SLOT = ResourceLocation.parse(
        "beyonddimensions:textures/gui/sprites/widget/slot_button.png");
private static final ResourceLocation SLOT_HOVERED = ResourceLocation.parse(
        "beyonddimensions:textures/gui/sprites/widget/slot_button_hovered.png");

g.blit(isHovered ? SLOT_HOVERED : SLOT, getX(), getY(), 0, 0, 16, 16, 16, 16);
g.renderFakeItem(stack, getX() + 1, getY() + 1);

注意事项

  • 路径大小写：文件名必须全小写；短名引用时不含 textures/gui/sprites/ 与 .png。
  • 精灵 vs 普通纹理：只有位于 textures/gui/sprites/ 下、且用 blitSprite 缩放的才是“精灵”；blit 需要显式纹理尺寸参数。
  • 版本风险：BD 计划更换 UI 框架，届时贴图路径 / 尺寸可能变动；引用 BD 贴图处应集中为常量，便于统一迁移（详见文档 28）。
  • 复用优先：新增界面优先复用 BD 的 slot_button 三态与模式图标，保持与 BD 原生界面一致的观感。
