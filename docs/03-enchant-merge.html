25 · 批量附魔工作站（附魔合并）

把网络中的单附魔书批量合并到单件装备：列出装备可附魔项、逐项滑条选等级、消耗附魔书 + 网络 XP 流体、取高合并

功能概述

批量附魔工作站是第 8 种远程工作站（id enchant_merge）。它是附魔分离器的逆操作：分离器把多附魔书拆成单附魔书，本工作站把网络中的单附魔书合并回一件装备。

  • 放入装备——单件可附魔装备（附魔书除外；已附魔装备允许升级）。
  • 候选由客户端构建——客户端基于装备可附魔列表 + 客户端网络视图（单附魔书最高等级 / 库存 / 等级位掩码）生成候选，服务端不再下发候选。
  • 逐项选等级——每项一个带档位刻度的等级滑条，范围 1 .. max(网络最高, 已有等级)；滑条等级与勾选状态解耦且记忆：取消勾选不改变滑条等级，重新勾选沿用。
  • 冲突禁用（随选择更新）——禁用判定依据当前选择列表：已有附魔（未被清除） + 已勾选（等级 > 0）构成“生效集合”，与生效集合冲突的新附魔项即时禁用；装备已有附魔永不因冲突禁用（含已有互相冲突的情况，合并时照常保留）。是否启用冲突判定读 enchantIgnoreConflict。
  • 精确等级优先——所选等级 S 若有同等级单附魔书，直接使用并按附魔分离器公式计费（网络 XP 流体）。
  • 高等级书拆分——无 S 级书时，取比 S 高且最接近的等级 L 书按折半递归拆分（等价：回存 (L-1)…S 各一本、S 级打到装备上）；每步（等级 −1）消耗普通书——默认 1 本/步（保留原附魔书载体），配置开启原载体消耗则 2 本/步；每步经验消耗可配，默认 0。
  • 取高合并 + 等级降序写入——装备已有该附魔只升不降；写入装备的附魔按所选等级从高到低排序（同级保持启用顺序）。
  • 预览 = 操作后物品悬浮框——合并按钮悬浮框直接渲染“操作后物品”的实际提示，并在对应附魔条目行尾以彩色后缀标注变化（[+] 新增 / [↑ 旧→新] 升级 / [↓ 旧→新] 降级；被移除项以删除线显示）。
  • 产物留槽——合并后的装备留在界面输入槽，关闭界面按“归还方向”处理。
与附魔分离器的分工分离器（文档 05）负责“书 → 多本单附魔书”；本工作站负责“单附魔书 → 装备”。两者共同覆盖附魔在网络中的拆解与重组。多附魔书不直接参与合并（需先经分离器拆开）。

候选构建流程（客户端）

GUI 每 10 tick 或装备变化时由客户端 rebuild() 重建（服务端不再计算/下发候选）：

装备校验非空、非附魔书、物品可附魔（已附魔允许升级）
扫描客户端网络视图menu.clientNetStorage → 仅取单附魔书的最高等级 / 库存 / 等级位掩码
遍历可附魔列表仅列适用附魔；标记冲突 / 无书 / 无可提升
启用项网络有书 且 最高等级 > 已有 且 不与“生效集合”冲突
禁用项无书 / 冲突 → 显示禁用贴图，不可点击、滑条不可操作
滑条等级记忆等级 → 否则已有等级 → 否则网络最高
冲突即时更新refreshConflicts()勾选 / 滑条 / 满级 / 清除 / 还原 后即时重算启用状态（不重新扫描网络）
提交合并操作
服务端只接受合并操作结果校验资源并执行（见下方流程）
生效集合定义已有附魔（未被清除）∪ 已勾选（等级 > 0）。已有附魔永不因冲突被禁用；仅新附魔项会因与生效集合冲突而禁用。

合并执行与计费（服务端）

C2SSubmitEnchantMergePacketcontainerId + [(附魔 id, 所选等级)]
服务端重新扫描网络书逐项校验：有书？适用？冲突放行？
所选等级 0 = 清除；低于已有 = 降级；高于已有 = 升级
费用计算精确等级项 calcCost([附魔@所选等级], 1)；拆分项 = 步数 × split_xp_cost（默认 0）
精确等级消耗对应等级书，按公式扣 XP
拆分消耗最接近高等级书，回存 (L-1)…S 各一本；每步扣 1/2 本普通书 + 可配经验
预检网络 XP 足够？每本书可用（simulate extract）？
任一不足 → 整体中止，不扣任何资源
执行预检通过后扣 XP 流体 → 逐本扣书 → 按等级降序写入装备（取高 / 清除 / 降级）
产物留槽音效 + 统计；触发候选重算
资源安全先整体预检再执行，避免“扣了书却没有 XP”或部分扣除；费用按所选等级（而非书的等级）计算，支持“高级书 → 低级附魔”的拆级用法。

费用公式（复用附魔分离器）

# 每项费用（默认规则）
(base_cost + (level - 1) × level_multiplier) × 附魔倍率
# 附魔倍率：high_cost_list 指定的附魔用其倍率，其余用 default_multiplier
# 可选自定义公式（use_formula = true）：
base + (level - 1) * multiplier        # 变量：base / level / multiplier / books
# 最终 XP 流体（mB）= 费用点数 × 20
配置复用计费项直接读取 enchantment_separation 分区的 base_cost / level_multiplier / default_multiplier / high_cost_list / use_formula / cost_formula，无需独立配置。
费用悬浮框悬停经验费用（文本带与铁砧同款暗色底）显示计费公式与逐项明细（精确等级 / 拆分行含普通书消耗），末尾按原版升级经验曲线由 0 级反推并显示「≈ 玩家从 0 级升到 X 级」（翻译键 xp.level_equiv）。

已知边界

  • UI 框架依赖（重要）：本工作站界面基于 Beyond Dimensions 现有 GUI 的布局/坐标/纹理（standard_background、slot_button、up_arrow 等）实现；BD 本体计划在下个版本更换 UI 框架，待其正式发布后需统一校对代码与新版 GUI。源码中所有相关类已加提示注释。
  • 仅支持网络中的单附魔书；多附魔书需先经附魔分离器拆分。
  • 候选仅列“有单附魔书且可提升/可新增”的项；网络无书时不出现（避免无效勾选）。
  • 同一附魔最高等级的多本书按精确存储键扣除；若同等级附魔书存在不同 NBT 变体，只取扫描到的首个键对应的库存展示与扣除。
  • 滑条可调低于已有等级（降级，免费）或取消勾选（清除，免费、不返还书）；高于已有为升级。清除 / 降级不消耗附魔书。
  • 冲突禁用为客户端体验（依据选择列表即时更新）；服务端在合并时仍以“装备已有附魔”做冲突复核，不阻止已有互相冲突的附魔保留。
  • 写入装备的附魔按所选等级降序排列；取消勾选不改变滑条记忆等级。
  • 合并为窗口内即时操作；并发改动网络（同 tick 内其他来源）由预检 + 实际扣除返回值兜底，极端情况下可能少合并一项而不扣费。
