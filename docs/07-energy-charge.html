16 · 网络能量充能（装备位 / 载具 / 女仆）

从网络 FE 库存为盔甲、手持工具/武器、Curios 饰品、女仆饰物与载具自动补能

功能概述

把维度网络的能量库存（EnergyStackKey.INSTANCE）作为“无线充电宝”，按配置周期为下列目标补充 FE：

  • 玩家盔甲槽（头盔/胸甲/护腿/靴子）
  • 主手/副手——工具与武器（平台工具标签、剑/挖掘工具/三叉戟/弹射武器、SW 枪械、带主手攻击伤害属性的物品、配置白名单）
  • Curios 饰品栏（charge_curios，需 Curios）
  • 女仆专用饰物栏（charge_maid_baubles，需 Touhou Little Maid）
  • SW / ywzj 载具（独立周期充电，见文档 16 / 19）

每个网络有独立的自动充电开关（默认开），可在网络 GUI 左侧按钮切换，状态随存档持久化；客户端按 netId 缓存开关用于按钮渲染。白名单支持物品 ID 与 #标签（默认含 AE2/AE2WTLib/RS/WCWT 无线终端）。

防丢失设计物品未接收的电量（receive 返回值差额）会回插网络，不会凭空消失；载具充电同样按接收量提取（0.6.x 修复）。

周期充电流程

每 tickServerTickEvent.Phase.ENDEnergyAmmoChargeHandler.tick(server)
player.tickCount % charge_interval == 0
取主网络DimensionsNet.getPrimaryNetFromPlayer
网络开关关闭 → 跳过
逐个目标槽位充电charge(stack, net)
计算缺口needed = max - stored
want = min(needed, 模式计算值)
从网络提取extract(EnergyStackKey.INSTANCE, want)
充入物品energy.receive(offered)
未接收余量回插网络
net.setDirty()Curios/女仆饰物用 setStackInSlot 触发同步

充电模式（energy_ammo.charge_mode）

模式计算说明
RATEwant = charge_rate每次固定提取（默认 10000 FE）
PERCENTAGEwant = ceil(needed × charge_percentage%)按缺失量百分比
PERCENTAGE_PLUS_RATEwant = 百分比 + 固定值混合模式
功率来源所有模式都先与物品缺口 needed 取 min，不会过充。

网络开关流程

客户端点击 EnergyChargeToggleBtn
C2SToggleEnergyChargePacket（空载荷，按当前菜单网络）
服务端权限校验manager / owner
NetworkAmmoDataNBT 键 energyCharge（默认 true）持久化
S2CEnergyChargeSyncPacket广播给网络内玩家
EnergyChargeState更新开关缓存并刷新按钮
已知边界载具充电（SW/ywzj）不检查该网络级开关，仅玩家与女仆路径生效。

配置项（energy_ammo 分区）

配置默认说明
charge_enabledtrue装备位网络自动充电总开关
charge_interval20充电间隔（tick，1–1200）
charge_rate10000每次提取 FE（RATE / 混合模式的固定部分）
charge_modeRATERATE / PERCENTAGE / PERCENTAGE_PLUS_RATE
charge_percentage10.0百分比模式的容量上限百分比（0–100）
charge_whitelistAE2/AE2WTLib/RS/WCWT 无线终端共 10 项额外充电物品列表，支持 #标签
charge_curiostrueCurios 饰品栏充电
charge_maid_baublestrue女仆专用饰物栏充电
白名单之外带主手攻击伤害属性的任意物品、平台工具/武器标签、SW 枪械与配置白名单物品也会被充电——如需严格限制请自行调整白名单并评估模组物品属性。
