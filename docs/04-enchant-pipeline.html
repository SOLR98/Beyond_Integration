26 · 附魔链路总览（分离 / 同类合并升级 / 批量合并）

从多附魔书拆分、单附魔书同级自动升级，到工作站批量合并到装备的完整流程与计费对照

三条链路总览

入网拦截链附魔分离多附魔书 → N 本单附魔书（扣 XP + 空白书）
入网拦截链同类同级自动合并单附魔书 + 网络同级书 → L+1（铁砧费用，默认关）
工作站批量附魔合并单附魔书 → 装备（精确等级 / 高等级拆分）
机制触发输入输出默认状态
附魔分离物品入网（自动）/ 命令手动多附魔书每附魔一本单附魔书全局与网络开关均需开启
同类同级自动合并单附魔书入网输入书 + 网络内同附魔同等级书一本 L+1 级书默认关闭（merge_same_level）
批量附魔合并工作站界面提交装备 + 网络中单附魔书附魔后的装备（留槽）工作站启用即可用
书形态流转多附魔书 --分离--> 单附魔书（多种等级）--同级合并--> 更高等级单附魔书 --批量合并--> 装备附魔。

一、附魔分离（入网拦截）

BD 插入链物品入网UnifiedStorageBeforeInsertHandler
网络开关 + 全局 enable + 多附魔书 + 非保护标记
判定StoredEnchantments > 1？
否 → 单附魔书走「同类合并」或放行
费用与资源calcCost(逐附魔) + 空白书 (N-1)×count
容量预检canStore / canOutput 全部通过才执行
扣费网络 XP 流体 + 空白书
扣原书extract 不足则回滚跳过
产出每附魔一本单附魔书 ×count
费用公式(base_cost + (level-1) × level_multiplier) × 附魔倍率 × 20 mB；use_formula 开启时用 cost_formula（变量 base/level/multiplier/books）。

二、同类同级自动合并（单附魔书升级，默认关闭）

插入链单附魔书入网数量 1、等级 L、开关 merge_same_level 开
L ≥ 附魔上限（含 Apotheosis）→ 放行
网络存在同附魔同等级书？
否 → 原书正常入库
费用铁砧合并费用等级 → 0→费用等级总经验点 × 20 mB
经验不足 → 放行原书
执行扣网络经验 + 扣网络那本同级书
产出 L+1 插回网络再次进入拦截链
自然级联直到无同级同类书 / 达上限 / 经验不足
铁砧费用等级Forge：稀有度系数（COMMON 1 / UNCOMMON 2 / RARE 4 / VERY_RARE 8）÷2（书）；Neo：getAnvilCost() ÷2；再乘结果等级（L+1），至少 1。

三、批量附魔合并（工作站）

候选构建（客户端）

装备入槽非附魔书且可附魔（已附魔允许升级）
客户端网络视图menu.clientNetStorage → 单附魔书最高等级 / 库存 / levelMask
遍历可附魔列表仅列适用附魔；无书 / 与“生效集合（已有 + 已选）”冲突 / 无可提升 → 禁用贴图且不可点（已有附魔永不因冲突禁用）
客户端渲染点击条目/复选框选中 + 滚轮/滑条调级（滑条等级记忆，取消勾选不改动）；面板内滚轮翻页；服务端只接受提交的合并操作

提交与执行（服务端）

C2SSubmitEnchantMergePacket附魔 + 所选等级 S
逐项判定S 级书存在？
精确等级消耗 1 本 S 级书；计费 calcCost(S)
拆分取最近高等级 L，steps=L−S；消耗 1 本 L 级书，回存 (L−1)…S 各一本；
计费 calcCost(S) + steps × split_xp_cost；普通书 steps ×（默认 1 / 开启原载体消耗 2）
预检经验流体 + 每本书 + 拆分普通书；任一不足整体中止
执行扣 XP / 普通书 → 扣书 → 拆分产出 → 按所选等级降序写入装备（0 清除 / 低于已有降级 / 高于已有升级）
装备留槽返回背包 / 网络按归还方向
拆分优先顺序精确等级 > 比 S 高且最接近的等级；拆分为折半递归的等价结果（回存 (L−1)…S 各一本 + S 级用于附魔）。

计费对照

机制经验消耗材料消耗备注
附魔分离 逐附魔 (base+(L−1)×mult)×倍率×20 mB 空白书 (N−1)×count 全局 + 网络开关双重控制
同类同级自动合并 铁砧合并费用等级 → 总经验点（20 mB/点） 网络内同附魔同等级书 1 本 产出入网自动级联
批量合并（精确等级） calcCost(S)（附魔分离公式） S 级单附魔书 1 本 按等级降序写入装备（取高；0 = 清除、低于已有 = 降级）
批量合并（拆分） calcCost(S) + 步数 × split_xp_cost（默认 0） L 级书 1 本；普通书 步数 ×（1/2） 拆出 (L−1)…S 各一本回存；拆分步骤本身默认免费，但合并到装备仍计费

分区项默认说明

enchant_tableignoreConflictfalse批量合并的冲突附魔放行（关闭时依“选择列表”禁用冲突新附魔）
