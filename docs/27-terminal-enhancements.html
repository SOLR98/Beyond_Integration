23 · BD 终端界面增强

左侧按钮栏接管与重排、RI 原生按钮屏蔽与替代、JEI 避让与网络数量角标、Shift 点击取物品、行数最大值跟随

功能概述

  • 左侧按钮栏接管：记录所有加入 BD 左侧栏的按钮（BD 原生 + 本模组 + 其他模组），统一重排——BD 原有按钮始终在最前（保持原序），本模组接管的按钮排在其后；放不下的按钮自动移到左侧新增列（不会超过 GUI 底边）。
  • RI（rs_integration）按钮屏蔽与替代：RI 原生的自动进食 EAT/SELECT/MODE/MENU 按钮全部屏蔽（不可见、不可点、不占位），改由本模组 3 个 16×16 侧栏按钮反射调用 RI 功能；每帧渲染前强制纠正坐标，避免被 RI 的每帧 setX/setY 拉回。
  • JEI 避让：把本模组自绘区域（右侧工作站模式按钮列、SW 弹药面板、左侧溢出列）告知 JEI，物品列表不会覆盖这些元素。
  • JEI 网络数量角标 + Shift 点击取物品：JEI 物品条目与左侧收藏栏物品右下角显示网络库存数量，悬停 tooltip 追加数量与取物提示，Shift+左键取一组 / Shift+右键取 1 个。默认仅在 BD 终端内生效；开启服务端 bd_tweaks.primary_net_jei_sync 后可在任意界面按主网络生效。
  • 行数最大值跟随：行数加满屏幕最大值后，调整窗口会继续按新屏幕最大值显示；手动减行后停止跟随。
与 RI 共存JEI 数量角标/点击取物品与 FTB 集成在检测到 rs_integration 时自动让路禁用（见文档 20 与本文末）。
