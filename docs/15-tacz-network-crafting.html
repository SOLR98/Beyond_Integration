04 · TACZ 枪械台网络合成

Gun Smith Table 配方「背包 + 网络」混合取料，支持批量合成、产物回存与 taczaddon 兼容

功能概述

TACZ 原版枪械台只能使用背包材料逐个合成。本模组为枪械台界面添加：

  • 网络材料数量显示——每个材料槽位右侧显示「+N」网络存量
  • 网络合成按钮——点按后从「背包 + 网络」混合取料（单次合成）
  • Shift 批量合成——最多 64 次连续合成
  • 产物回存网络——可切换产物直接存入网络而非掉落/入背包
  • CraftToast 通知——合成完成弹出角标提示

合成流程：客户端点击按钮 → TaczCraftPacket(recipeId, count, toNetwork) → 服务端 TaczCraftManager 先模拟扣料再真实扣料 → 产物入背包/网络 → 失败自动回滚。0.6.0 起材料查询改用配方驱动定向扫描（RecipeMaterialScanner），不再全桶遍历。

网络合成流程（核心）

客户端点击合成按钮（mixin 修改 OnPress → 不再发 TACZ 原版包）
Shift 按下 → count=64；否则 1
C2STaczCraftPacket(recipeId, count, toNetwork)
服务端TaczCraftManager按 recipeId 取 GunSmithTableRecipe
取料来源合并背包 + 当前主网络
模拟阶段simulate：逐槽检查 inInv + inNet ≥ need
任一不足 → 回滚，返回失败
扣料阶段先扣背包，不足部分从网络 extract
产物方向toNetwork ?
入网络产物 insert 回统一存储；余量以掉落物归还玩家
入背包产物放入玩家背包（背包满则掉落）
循环计数crafted++，直到 crafted ≥ count 或材料不足
S2C响应告知客户端合成数量 + 刷新材料计数
客户端CraftToast弹出「已合成 ×N」
已知边界① 合成冷却配置 craft.cooldown_ms 已定义但未使用，客户端可连续发包批量消耗网络材料；② 计数快照在发包时生成，多玩家同时合成同网络存在竞态窗口（最终以服务端 simulate 为准，不产生复制）。

taczaddon 兼容

taczaddon 自 1.1.8.1 起进行大幅重构（NeoForge 侧对应 1.1.8.2 起重构），本模组对其重构后的版本系列做兼容注入；旧结构版本（1.1.8 及更早）不注入。设计目标：

  • 模式互斥——网络模式下材料计数 = 背包 + 网络（隐藏 addon 的附近容器外部源）
  • 按钮接管——网络模式下点击合成改走本模组服务端网络合成，不走 addon 外部容器流程
  • 顺序无关——双方对合成按钮的 Mixin 包装顺序任意均正确工作
  • BD 容器源过滤——craft.block_bd_reader 开启时 BD 网络方块不被 addon 当作容器源（避免整网全量槽遍历）

Forge 1.20.1（4 个兼容 Mixin）
