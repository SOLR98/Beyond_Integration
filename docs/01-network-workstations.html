01 · 网络工作站（七合一菜单）

远程使用合成台 / 铁砧 / 切石机 / 砂轮 / 锻造台 / 存储 / 附魔台，材料直接取自维度网络

功能概述

本模组的核心功能之一：无需摆放任何工作站方块，玩家通过 6 个快捷键（默认未绑定，可在控制设置中分配）或网络界面右侧的工作站按钮，即可远程打开基于自己主网络的 7 种工作站界面。材料从网络统一存储（UnifiedStorage）自动补料，产物可选择放入背包或回存网络。所有菜单继承 Beyond Dimensions 的 DimensionsNetMenu，直接操作网络存储，支持物品 / 流体 / 能量三种键类型。

注意「存储」菜单没有独立快捷键——它由 BD 原版便携终端打开，本模组仅补充注册了同名菜单类型并做界面扩展（附魔分离开关、自动充电开关、物品保护、弹药面板、工作站模式按钮）。
附魔台0.6.5 新增第 7 种工作站，功能较多，独立成篇（见 文档 02）。

各工作站要点

工作站特色逻辑
合成台 DimensionsCraftMenu网络自动补料：每次取走产物后从网络/背包补齐 3×3 网格（补料总额恒为 1 组，防复制）；结果计算走 BD 的 slotChangedCraftingGrid；支持 JEI 一键填充（RecipeFillPacket）；Shift 批量合成；桶/流体桶：网络只有流体（+空桶）时自动转换填充与补料（见"桶 / 流体桶支持"节）
铁砧 DimensionsAnvilMenu改名走 SetAnvilNamePacket；费用由服务端重算（不信任客户端）；XP 计费双模式：LEVEL（扣等级，levelCap 上限）/ POINTS（20 点 = 1 级，优先从网络 XP 流体扣，不足补玩家经验）；0.6.x 扩展附魔等级突破与解禁（见下表）；物品保护标记的物品不可覆盖
切石机 DimensionsCutMenu原料耗尽时自动从网络补料；配方索引 DataSlot 同步
砂轮 DimensionsGrindMenu标准砂轮逻辑，自动补料
锻造台 DimensionsSmithMenu模板/底材/附加三槽自动补料
存储 DimensionsStorageMenuBD 终端菜单的扩展壳：附魔分离开关按钮、自动充电开关按钮、物品保护（ProtectItemPacket）、SW 弹药面板（AmmoPanelExtension）
附魔台 DimensionsEnchantMenu网络化附魔：功率来源/预览/刷新/宽松选魔/解限，详见 文档 02

桶 / 流体桶支持

能力状态说明
桶入网自动分离✔ 已实现bd_tweaks.bucket_separator_enabled（默认开）：含流体桶入网拆为"流体 + 空容器"；关闭后原样入网。配套 bucket_separator_bucket_only（默认开，仅拆 BucketItem 子类，不再自动拆水瓶）与 bucket_separator_excluded_items（排除项，默认含森罗酒馆果汁桶）
本模组合成台（3×3）✔ 已实现JEI 一键填充 / 取走补料 / 自动补料均支持"流体 + 空桶"转换（宽松语义，空桶可选）
TACZ 枪械台合成✔ 已实现材料桶不足时按流体量直接扣除（1 桶 = 1000 mB，空桶有则一并扣）
BD 终端合成 JEI 填充✔ 已实现客户端池注入（TransferHelper 流体虚拟量）+ 服务端 extractFromStorage 流体回退，走 BD 原版流程（缺失高亮 / maxTransfer 倍率保留）
BD 工作台自动补料（取走结果）✔ 已实现AutoRefillResultSlot 补扣提取不足时用网络流体替代（1.20.1 生产环境 m_142406_ / 开发环境 onTake 双注入，调用 owner AbstractUnorderedStackHandler），合成格桶保留
合成格空 / 缺桶自动填充— 已忽略无配方上下文时的主动填充不在计划内（JEI 填充 / 取走补料 / 自动补料已覆盖实际使用场景）
已知限制流体桶识别依赖 FluidUtil 流体 capability（无 capability 的容器不参与转换）；转换均为"宽松语义"——网络无空桶时仅扣流体生成桶（合成格/取出场景），入网分离仍要求可推导空容器；桶合成转换已覆盖本模组合成台、TACZ 与 BD 原版工作台/终端。
