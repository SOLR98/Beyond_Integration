18 · 悬停快速存储（收纳袋式存入网络）

在任意容器界面悬停槽位左键点击，把物品快速存入（或取出）绑定网络的终端

功能概述

模仿原版收纳袋（Bundle）的交互：当光标物品或悬停槽位物品中任意一方是绑定网络的终端（NBT 含 NetId）时，左键点击即可双向快速转移：

  • 存入网络——光标持物、悬停槽位是联网终端：光标物品整组存入该网络，余量留在光标
  • 从网络取出——光标持联网终端、悬停槽位有物品：把槽位物品存入光标终端的网络（走 safeTake 触发 mayPickup/onTake，避免结果槽刷取）

客户端在可快速存入的槽位左上角绘制绿色 + 提示；服务端校验玩家是网络成员（owner/manager/member）后才执行。

组件构成

组件类职责
点击注入mixin/NetedItemClickMixin注入原版 Item.overrideOtherStackedOnMe / overrideStackedOnOther（仅 PRIMARY、仅服务端）
业务处理handler/HoverInsertHandler权限校验 / insert / safeTake / 余量归还
视觉提示client/HoverStoreOverlay悬停槽位左上角绿色 +
物品提示handler/NetworkIdTooltipHandler（Forge）
handler/ItemTooltipHandler（NeoForge）		tooltip 显示“可快速存入网络”等提示

交互流程

客户端容器界面悬停槽位HoverStoreOverlay 判定任一物品绑定网络
绘制绿色 +（guiLeft + hovered.x - 2）
左键点击原版物品覆写链触发
C2SServerboundContainerClickPacket
服务端NetedItemClickMixin读取终端 NBT → HoverInsertHandler.tryInsert
权限校验net.isOwner || isManager || getPlayers().contains(uuid)
无权限 → action bar hover_insert.no_permission
存入storage.insert(new ItemStackKey(物品副本), 数量, false)
insert 返回余量（leftover）
余量处理正向：留在光标；反向：returnToPlayer（背包满则掉落）
提示hover_insert.success / hover_insert.failed

提示与边界

项说明
触发条件仅左键（ClickAction.PRIMARY）；槽位需 allowModification（反向）
权限网络成员即可（非仅 owner/manager）
匹配物品按 ItemStackKey 精确匹配（NBT 变种视为不同键）
tooltip携带网络 ID 的物品显示网络 ID；悬停联网物品且光标持物时显示“可快速存入”
已知边界客户端 HoverStoreOverlay 与服务端 HoverInsertHandler 各自实现了“可快速存入”的判定条件，修改其一时需同步另一侧。
