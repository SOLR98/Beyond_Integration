12 · 网络数据包架构

Forge：SimpleChannel 单通道 40 包条件注册 · NeoForge：CustomPacketPayload 41 包 · 主线程化处理

架构总览

  • Forge 通道：beyond_integration:main，SimpleChannel，协议版本 "1"（不匹配拒绝连接），registerMessage 按注册顺序分配 ID
  • NeoForge 通道：RegisterPayloadHandlersEvent + registrar("1")，全部 CustomPacketPayload（record + StreamCodec），41 个 payload 全部无条件注册
  • 编码：Forge 为 record + 静态 encode/decode/handle 三件套（FriendlyByteBuf）
  • 线程安全：所有 handle 统一 enqueueWork(...) 切到主线程再操作游戏对象
  • 条件注册（Forge）：SW/TACZ 相关包仅在对应模组加载时注册，保证双侧包 ID 一致；NeoForge 改为全部注册、运行时判定依赖

NeoForge 数据包清单（41 个）

NeoForge 侧全部实现 CustomPacketPayload，其中 network/payload/ 子包 13 个使用新风格 Type + StreamCodec.composite/unit/of 写法，其余沿用简写风格。

分类包说明
工作站（7）payload/OpenStorageMenuPayload（含 apoth 标志）、payload/SetAnvilNamePayload、payload/RecipeFillPayload、payload/ProtectItemPayload、payload/CleanWorkstationPayload、payload/RefreshEnchantPayload、payload/EnchantCluesPayload对应 Forge 的基础包（新风格）
开关（6）ToggleEnchantSeparationPacket / EnchantSeparationSyncPacket / RequestEnchantSeparationPacket、ToggleEnergyChargePacket / EnergyChargeSyncPacket / RequestEnergyChargePacket附魔分离 + 自动充电
SW（6）SuperbAmmoStatusResponsePacket（双向）、RequestSuperbAmmoStatusPacket、RequestSuperbAmmoExtractPacket、SuperbAmmoDeltaS2CPacket、RequestItemAmmoPacket、ItemAmmoResponsePacket状态全量/增量、提取、ITEM 现查
TACZ（6）RequestAmmoCountPacket、AmmoCountResponsePacket、TaczAmmoPushPayload、RequestNetworkItemsPacket、NetworkItemCountsPacket、TaczCraftPacket弹药计数/推送、枪械台材料与合成
ywzj（1）YwzjVehicleDataResponsePacket载具网络数据推送（见文档 19）
上表仅列早期核心分类；共 41 个 payload 全部无条件注册，完整清单见 network/PacketHandler 与《功能与实现总览》。
