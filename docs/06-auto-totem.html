08 · 网络图腾

死亡时自动从维度网络抽取不死图腾；一个功能、两种触发机制（基础触发 / 强化触发：抢先拦截 + setHealth 直杀加价）

功能概述

玩家受到致命伤害时，若自己的主网络中存有不死图腾，本模组自动提取并使用，效果与原版主手图腾完全一致：

  • 回满生命值（默认 1 点，可配置回满）并清除全部效果
  • 施加生命恢复 II（45 秒）+ 伤害吸收 II（5 秒）+ 抗火（40 秒），参数对齐原版
  • 触发原版图腾统计/成就/粒子动画/音效/弹出动画（实体事件 35）
  • 图腾从网络消耗（仅网络来源，不取玩家背包）
  • 消耗提示：改用快捷栏上方 HUD 短暂显示（原为聊天栏消息）

同一功能提供两种触发机制：基础触发（死亡事件层）与强化触发（事件版 + Mixin 版双实现）， 可独立开关、也可同时使用。

女仆图腾女仆死亡救援由 MaidAutoTotemHandler 独立处理（见文档 18 与《女仆相关能力边界》）；强化触发仅面向玩家。

两种触发机制（同一网络图腾）

维度基础触发 AutoTotem强化触发 Revive
目标实体玩家 + 女仆仅玩家
拦截层死亡事件（LivingDeathEvent / 女仆 MaidDeathEvent）双实现：事件版（LivingDeathEvent）+ Mixin 版（注入 checkTotemDeathProtection RETURN，抢在 die() 之前，不产生死亡事件）
死因识别无LivingDamageEvent（LOWEST）致死指纹，按 tick 判定"正常伤害致死 vs setHealth 直杀"
图腾消耗固定 1 个1 + 额外：setHealth 直杀默认再 +1（可配 0–64 或关闭）
冷却auto_totem.cooldown_seconds（两者共用；强化触发的事件版与 Mixin 版共享同一冷却）
复活动作回血 / 恢复上限 / buff / 无敌帧 / 图腾动画相同 + deathTime/hurtTime/Pose 重置（reset_death_time）+ 原版统计与进度触发
女仆支持有（女仆关联终端网络）无
定位基础触发只处理"正常死亡事件"；强化触发的 Mixin 版在 die() 前强制返回 true （对 FE 等走 checkTotemDeathProtection 的击杀同样有效），并用指纹机制让"直杀"付出更多图腾代价（防廉价秒杀）。
同时开启的注意Mixin 版最先拦截时死亡事件不会发生，基础触发不触发（无双扣）； 但 Mixin 版关闭、事件版与基础触发同开时，两者都在 LivingDeathEvent 上竞争，可能先后各扣 1 个图腾——建议按需二选一。

触发流程（基础触发）

事件LivingDeathEvent（玩家死亡）
服务端前置检查开关开启 / 非黑名单伤害 / 冷却已过
respect_bypasses_invulnerability=true 时虚空/命令伤害直接放行
取主网络DimensionsNet.getPrimaryNetFromPlayer(player)
无网络 → 放行死亡
提取图腾extract(ItemStackKey(不死图腾), 1)
extract 返回值 ≤ 0 → 放行死亡
取消死亡event.setCanceled(true) + net.setDirty() + 记录冷却
统计与成就awardStat(ITEM_USED) + USED_TOTEM 触发器
恢复最大生命（可选）移除 max_health 负面修饰符
血量heal_to_full ? 满血 : setHealth(1)
效果 + 无敌帧清效果 / 3 buff / invulnerableTime = 20
实体事件 35粒子 + 音效 + 弹出动画

触发流程（强化触发）

指纹LivingDamageEvent（LOWEST）记录"致死级伤害"tick（health - amount ≤ 0）
死亡入口二选一
事件版LivingDeathEvent：黑名单/无敌标签/冷却校验 → 提取 1+额外图腾 → 取消死亡
revive.event_enabled
Mixin 版checkTotemDeathProtection RETURN：原版图腾未触发时提取 1+额外图腾 → 强制返回 true（不进 die()）
revive.mixin_enabled
直杀判定无同 tick 致死指纹 → 按 setHealth 直杀额外扣图腾（extra_totem_on_set_health_death）
复活动作统计/进度 + 恢复上限 + 回血 + 死亡时间/姿态重置 + buff/无敌/动画
图腾不足提取量不足总消耗时已提取部分自动回滚，按正常死亡处理。

配置项

通用项统一在 auto_totem 分区（两种触发共用）；强化触发独有项在 revive 分区。

auto_totem 分区（通用）

配置默认说明
enabledtrue基础触发功能总开关（强化触发不受此开关控制）
cooldown_seconds10触发冷却（秒，0–3600；强化触发的事件版与 Mixin 版共享）
damage_blacklist["outOfWorld","fellOutOfWorld","genericKill","command"]不触发的伤害消息 ID；空列表 = 全部伤害可触发
respect_bypasses_invulnerabilityfalsetrue = 虚空/命令等无视无敌伤害不触发（恢复原版语义）
restore_max_healthtrue恢复被削减的最大生命值上限
heal_to_fullfalsetrue = 触发后回满血而非 1 点

revive 分区（强化触发独有）

配置默认说明
event_enabledtrue事件版触发开关（false 时不注册处理器，零事件开销）
mixin_enabledtrueMixin 版触发开关（false 时方法体内直接返回）
仅配置文件可调，不在配置界面显示
extra_totem_on_set_health_deathtruesetHealth 直杀时额外消耗图腾
extra_totem_count1直杀额外消耗数量（总消耗 = 1 + 该值，0–64）
reset_death_timetrue重置 deathTime/hurtTime/姿态，撤销死亡表现与移除计时
配置界面强化触发的独有项显示在 Cloth Config「网络图腾」分类内（以「网络图腾（强化触发）」小标题分隔）；通用项即该分类上半部分。
