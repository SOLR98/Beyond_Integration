功能篇

远程工作站、附魔链路、网络资源与维度网络增强。

01 · 网络工作站

  • 功能：6 个快捷键 / 终端按钮远程打开 7 种工作站（合成台 / 切石机 / 锻造台 / 砂轮 / 铁砧 / 存储 / 附魔台），材料从主网络自动补料，产物可回背包或回网络；桶与流体桶自动转换补料；铁砧支持改名与服务端重算费用（LEVEL / POINTS 双模式）。
  • 实现：init/ModMenus · feature/crafting/Dimensions*Menu(×7) · client/gui/Dimensions*GUI · client/BDKeyBindings · network/OpenStorageMenuPacket · handler/BucketFluidHelper · BucketSeparatorHandler；Mixin BdBucket* 系列、DimensionsCraftGUIMixin、DimensionsTerminalCraftGUIMixin。
  • 配置：workstations.enabled；bd_tweaks.bucket_separator_enabled；anvil.*；客户端 workstation_order。
  • 双分支：NeoForge 菜单位于 init/、包为 payload/OpenStorageMenuPayload，并额外有 Apotheosis 附魔菜单（入口暂未启用）。

02 · 网络附魔台

  • 功能：第 7 种工作站，不依赖书架；功率来自 FIXED / NETWORK_XP / PLAYER_LEVEL；三槽预览、刷新、宽松选魔、忍冲突 / 反复附魔 / 免燃料 / 解限 / 费比缩放 / 宝藏附魔。
  • 实现：feature/crafting/DimensionsEnchantMenu · client/gui/DimensionsEnchantGUI · network/RefreshEnchantPacket / EnchantCluesPacket · client/widget/EnchantIconBtn（无 Mixin）。
  • 配置：enchant_table.*；客户端 enchant_preview_on；Neo 额外 apothQuanta/apothArcana 与 enchant_table_apoth_mode。
  • 双分支：Neo 有神化附魔菜单 / 界面（入口暂未启用），包为 payload/。

03 · 批量附魔工作站

  • 功能：第 8 种工作站 enchant_merge；从网络单附魔书批量合并到装备；逐项滑条选级、冲突即时刷新、精确等级优先、高等级书递归拆分、取高合并、悬浮预览。
  • 实现：DimensionsEnchantMergeMenu · client/gui/DimensionsEnchantMergeGUI · network/SubmitEnchantMergePacket/Payload · 复用 EnchantmentBookSeparatorHandler（无 Mixin）。
  • 配置：enchant_merge.enable/consume_original_book/split_xp_cost；workstations.activation.costs。
  • 双分支：注册入口 ClientRegistrar（Forge）vs ClientEventHandler（Neo），包路径不同。

04 · 附魔链路总览

  • 功能：总览附魔三链路——分离（多→单）→ 同类同级自动升级 → 工作站批量合并到装备的流程与计费对照。
  • 实现：文档型总览，核心实现同 05 / 03（EnchantmentBookSeparatorHandler + DimensionsEnchantMergeMenu）。
  • 配置：见 05 / 03。
  • 双分支：铁砧费用为 Forge 稀有度系数 vs Neo getAnvilCost()；cost_formula 标注为 Forge。

05 · 附魔分离器

  • 功能：多附魔书入网自动拆为单附魔书（扣网络 XP，20 mB/点 + 普通书 (N−1)）；命令批量分离；总开关 + 每网络开关；费用公式；容量预检回滚；保护标记跳过；可选同类同级自动升合并。
  • 实现：feature/enchant/EnchantmentBookSeparatorHandler · FormulaParser · NetworkAmmoData · client/widget/EnchantToggleBtn · Toggle/EnchantSeparationSync/RequestEnchantSeparation 包 · command/EnchantSeparateCommand（无 Mixin）。
  • 配置：enchantment_separation.*（enable/base_cost/…/merge_same_level/use_formula/cost_formula）；网络级 NBT enchantSeparation。
  • 双分支：分离核心路径 feature/enchant/（Forge）vs handler/（Neo）。

06 · 网络图腾

  • 功能：致命伤害自动从主网络取不死图腾（效果对齐原版）；仅网络来源；强化触发（事件 + Mixin 双实现，setHealth 直杀额外加价）；女仆死亡救援独立；消耗提示改 HUD。
  • 实现：AutoTotemHandler · ReviveSupport · ReviveFingerprintHandler · SetHealthReviveHandler；Mixin LivingEntityTotemReviveMixin；HUD HudHintPacket/HudHintPayload + client/HudHintState。
  • 配置：auto_totem.*、revive.*。
  • 双分支：无。

07 · 网络能量充能

  • 功能：网络 FE 作为无线充电宝，周期为盔甲 / 手持 / Curios / 女仆饰物 / 载具充电；RATE / PERCENTAGE / PERCENTAGE_PLUS_RATE；每网络开关；未接收电量回插网络。
  • 实现：EnergyAmmoChargeHandler · ChargePlatform · EnergyChargeAccessor · Toggle/EnergyChargeSync/RequestEnergyCharge 包 · EnergyChargeState/Btn；Mixin VehicleEnergyChargeMixin · AmmoConsumerMixin · DimensionsNetMixin。
  • 配置：energy_ammo.*（charge_enabled/interval/rate/mode/whitelist/curios/maid_baubles）。
  • 双分支：Forge feature/ammo/sw + ForgeChargePlatform；Neo handler/ + NeoChargePlatform，支持流体燃料。

08 · 终端熔炼

  • 功能：联网便携终端作熔炉输入，取出时批量烧炼全网络可烧炼物品，经验按 20 mB/点折算入网，终端本身不消耗。
  • 实现：TerminalSmeltRecipe/Serializer · FurnaceTerminalSmelter · FurnaceTerminalEventHandler；Mixin NetedItemMixin（保护标记产物）。
  • 配置：bd_tweaks.furnace_terminal_smelt_all、xp_rod_enabled。
  • 双分支：包路径与配方目录 recipes/ vs recipe/；仅 RecipeType.SMELTING。

09 · 悬停快速存储

  • 功能：容器界面悬停槽位左键，在光标与联网终端间双向快速存入 / 取出；绿色「+」提示；服务端成员权限校验；精确 ItemStackKey；safeTake 防结果槽刷取。
  • 实现：HoverInsertHandler · client/HoverStoreOverlay · NetworkIdTooltipHandler（Neo：ItemTooltipHandler）；Mixin NetedItemClickMixin。
  • 配置：无。
  • 双分支：tooltip 类不同，其余一致。

10 · 工作台献祭激活

  • 功能：可选平衡项——使用工作台需先献祭对应原版工作台（网络级，一次激活全网可用），合成台 / 终端除外；服务端权威校验；启用列表随包下发；命令重置。
  • 实现：WorkstationActivation · NetworkAmmoData · Activate/Request/Sync 包 · WorkstationActivationCache；Mixin DimensionsNetMixin。
  • 配置：workstations.activation.enable / costs。
  • 双分支：Neo 网络包位于 payload/，其余一致。

11 · 维度网络通道过滤

  • 功能：net_pathway 标记槽白名单（启用 / 仅接收输入 / 模糊），空标记不暴露任何物品；对外能力暴露裁剪；标记槽行数 1~6；方块配置破坏保留 / Shift+左键复制 / 清 NBT 配方。
  • 实现：NetPathwayFilteredStorage · NetPathwayFilterMenu/GUI · NetPathwayInteractionHandler · NetedBlockConfigNbt；Mixin NetPathwayBlockEntityFilterMixin · NetedBlockEntityNetPathwayDataMixin · NetedBlockKeepFilterNbtMixin。
  • 配置：bd_tweaks.net_pathway_filter_rows、bd_tweaks.neted_block_keep_nbt。
  • 双分支：清 NBT 配方目录 recipes/ vs recipe/；过滤开关为每方块 NBT（随 QuickData 同步）。

12 · 经验棒增强

  • 功能：解除目标等级上限（默认 238609312）；BATCH 分批发放防跳变；DIRECT 直设（网络 XP 优先，1 点 = 20 mB，二分反解，零头回插）。
  • 实现：XpGrantHelper · XpDirectGranter；Mixin XpUtil · XpExchangeSettings · XpExchangeItem · XpExchangeGUI。
  • 配置：bd_tweaks.xp_rod_enabled/max_target_level/grant_batch_size/grant_mode。
  • 双分支：无。

网络弹药系

网络弹药与网络绑定相关联动；16、19 为载具支持。

13 · SW 虚拟弹药系统

  • 功能：SW 弹药 / 弹药盒 / 弹药箱入网折算 5 类虚拟弹药；射击优先扣网络，不足补扣玩家；创造箱无限；轮询差分推送 + 扣弹即推；HUD 显示网络名 / 弹药 / ∞。
  • 实现：SuperbAmmoInsertHandler · NetworkAmmoData · SwAmmoTracker/PollingService · client/SuperbAmmoCache；Mixin DimensionsNetMixin · AmmoConsumerMixin · GunDataCountMixin（Neo GunDataMixin） · VehicleAmmo/NetworkSync/HudNetwork · AmmoBarOverlay。
  • 配置：sw_ammo.ammo_poll_enabled / interval_ticks；ammo_extract.mappings。
  • 双分支：类路径 feature/ vs handler/；SW 系 6 包仅 Forge 条件注册。

14 · TACZ 网络供弹与装填

  • 功能：弹药盒入网拆箱按弹药 ID 计数；射击 / 装填自动从网络取弹；创造弹药无限；接管直读背包枪械 R 键换弹全链路；HUD；查询缓存 + 10 tick 差分；Tacz-Unidict 兼容。
  • 实现：AmmoBoxExtractHandler · TaczAmmoExtractor · NetworkAwareAmmoHandler · TaczAmmoTracker/PollingService · TaczAmmoCache · compat/tud/TudAmmoCompat；Mixin AbstractGunItem · ModernKineticGunScriptAPI · GunAnimationStateContext · LocalPlayerShoot · ReloadKey · LocalPlayerReload · LivingEntityReload（Forge） · GunHudOverlay · GunDataCount。
  • 配置：tacz_ammo.ammo_poll_enabled / interval_ticks。
  • 双分支：换弹接管 Mixin 标注为 Forge；TACZ 系 5 包 Forge 条件注册。

15 · TACZ 枪械台网络合成

  • 功能：材料槽显示网络存量「+N」；一键 / Shift 批量（≤64）用「背包 + 网络」混合取料合成；产物可回存，余量归还；配方驱动定向扫描；完成 CraftToast 角标；taczaddon 重构版兼容（模式互斥 / 按钮接管）。

  • 配置：craft.cooldown_ms / max_depth / block_bd_reader；客户端 tacz_smith_use_network / tacz_smith_output_to_network。
  • 双分支：taczaddon 注入点与数量不同，版本门控 Forge ≥1.1.8.1 / NeoForge ≥1.1.8.2。

16 · 载具绑定与网络充电（SW）

  • 功能：手持联网物品右键 SW 载具绑定（NBT Net_id）；周期抽取网络 FE 充电（RATE / PERCENTAGE）；武器消耗网络弹药；驾驶 HUD；快照差分推送与持久化。

17 · 哨戒机械臂联动

  • 功能：手持联网物品右键底座绑定并把物品加入弹药箱；装弹从网络直取（≤9000）；假玩家第 9 格塞网络标记使 TACZ/SW 感知网络；NBT 持久化；Neo 无 Sable 兼容修复。

18 · 女仆联动

联动篇

弹药/绑定之外的第三方集成：FTB、Thirst、Goety。

  • 功能：检测 / 消耗 / XP / 流体 / 能量任务读写主网络；多候选选择提交 GUI；奖励领取选择 GUI 与单条 Shift 入网；tooltip 网络数量；检测到 RI 时让路。

21 · 口渴（Thirst）集成

  • 功能：喂食器补水档位；只消耗标记槽物品 / 流体；4 档纯净水流体（仅流体，无方块 / 桶）；终端取水打纯度；网络熔炉按标记执行 Thirst 熔炼提纯（可配速度）；机械动力（Create）灌装配方 + 沙滤提纯。

  • 双分支：Capability vs DataAttachment、NBT vs CUSTOM_DATA、ForgeEventFactory vs EventHooks。

32 · Goety 联动（网络灵魂源）

  • 功能：把维度网络作为与「方舟 / 图腾」并列的独立灵魂源（原版优先：消耗先 Arca/图腾、不足补网络，吸收先填满原版、溢出才入网）；灵魂源激活仪式；牢笼魂源（终端 / 连接宝石 / 通道替代牢笼）；击杀溢出沉淀与手动转化；网络复活（原版无法复活时兜底，可落点为方舟）与折扣；HUD 追加第三条网络灵魂条；原版仪式环境绕过（触发方块）。
  • 实现：SoulEnergyType/SoulEnergyStackKey/SoulEnergyAccess/SoulVanillaSource/SoulKeyRegistration · SoulSourceRitual/ModRitualFactories/SoulArkActivation · NetworkSoulSource/SoulGainHandler/SoulManualConvert；Mixin CursedCageBlock/CursedCageBlockEntity · DarkAltarBlockEntity · SEHelper · SoulRevive · RitualRequirements · SoulEnergyGui；数据包灵魂源仪式配方。
  • 配置：[goety_soul]（enabled/require_activation/source_kill/kill_ratio/source_manual/direct_main_net/max_souls/network_discount/network_revive/network_revive_to_arca/debug）· [goety_ritual]（env_bypass/pathway_count/connect_count/radius/pathway_cage）。
  • 分支：仅 1.20.1-FORGE（Goety 仅此分支）。

36 · 网络药水护符（Apotheosis）

  • 功能：网络里的药水护符对「主网络玩家 / 绑定网络的女仆」生效；效果按类型去重（最高等级，同级优先无法破坏）；门槛为无法破坏 / 自身经验修补 / 网络献祭解锁；无法破坏免费，其余每次扣网络 XP 流体（默认 1 XP = 20 mB）。
  • 实现：NetworkPotionCharmHandler（按网络缓存 + BdSubscriptionHub 订阅 delta，仅护符变动才重扫）· PotionCharmMode · ApothCharmSupport · PotionCharmAccessor + DimensionsNetMixin · MaidPotionCharmHandler；包 CyclePotionCharmModePacket/SacrificeMendingPacket/PotionCharmSyncPacket/RequestPotionCharmPacket；命令 insert potionCharm。
  • 配置：[potion_charm]（enabled / interval / refresh_lead_ticks / mending_xp_cost）。
  • 两条 1.20.1 线：旧线有 PotionCharmToggleBtn（BD 网络界面按钮，循环模式 + 献祭）；新线（NEW_FORGE_1.20.1）按钮随旧 GUI 删除，包无发送方 → 只能以默认「仅玩家、未解锁经验修补」运行，待补 BdPage 页面。
