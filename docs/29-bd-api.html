14 · Beyond Dimensions API 参考（0.7.30）

BD 全部公开 API 整理 · 源码版本 beyonddimensions-0.7.30-1.20.1 · 硬依赖（mandatory）

总览

  • modid：beyonddimensions（BDConstants.MODID）
  • 事件总线：全部事件经 Forge 总线 MinecraftForge.EVENT_BUS.post(...) 派发（非 NeoForge）
  • 网络通道：BDPackets.INSTANCE，SimpleChannel beyonddimensions:simple_channel，协议版本 "1"
  • 包结构：api/（稳定 API）与 common/（实现，可参考但随版本变动）
  • 核心模型：DimensionsNet（网络，SavedData）→ UnifiedStorage（无序统一存储，键值 = IStackKey + long 数量）
重要① PlayerNetIndex / NetRegistryIndex 为包私有类，非公开 API，只能经 DimensionsNet 静态方法间接访问；② AbstractUnorderedStackHandler 无 getSlotMaxSize() getter——槽位上限以 public int slotMaxSize 字段直接暴露；③ 本版本不存在自定义 "conversion" 配方类型与 IDimensionsNetGUIExtension UI 扩展接口（Beyond Integration 自带的 conversion JSON 是供 BD 消费的 datapack 内容，实际由 BD 内部逻辑处理）。
0.7.30 变更相对 0.7.27：存储 UI 左侧按钮改为侧边栏布局；新增物品 ID 搜索（luo-zi 贡献）；经验棒最大目标等级上调为 21863。以上为 BD 自身变化，未破坏本文列出的公开 API；BI 的 bd_tweaks 经验棒增强在此基础上继续放宽上限（默认 238609312，见文档 12）。
