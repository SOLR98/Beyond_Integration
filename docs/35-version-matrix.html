怎么读这张表

  • 0.7.30 线是两个正式分支：功能最全，差别主要在加载器（Forge / Neo）与 BD API 形态；1.21.1 多一个 Apoth 附魔台、少一个网络药水护符。
  • 0.8.x 线是围绕 BD 新界面体系的重做：NEW_FORGE_1.20.1 已把大部分逻辑迁完并用 BdPage 补齐喂食器 / 经验棒 / 通道界面； NEW_NEOFORGE_1.21.1 目前只有工作台与存储页的 GUI 骨架，功能逐项待移植。
  • 需要跨线搬运时注意：0.7.30 → 0.8.x 的界面/菜单代码不能平移（BD 0.8 换 CompixelUI，扩展点改为 BdPage、菜单改 SyncedMenu/BDMenuResources）； 插入规则从 BeforeInsertHandler 改为 InsertPlan；SW 弹药从虚拟计数改为散装物品。
待补/待确认 ① 1.21.1_NEOFORGE（0.7.30 线）的经验棒修复、EMI 快捷等标 ? 的项需核对源码； ② NEW_NEOFORGE_1.21.1 绝大多数功能仍 ➖，需按 0.8.x-1.20.1 的清单逐项移植； ③ 0.8.x-1.20.1 的缺口见上一节说明（工作台、磁铁/漏斗页、终端、EMI、附魔书上限）；
