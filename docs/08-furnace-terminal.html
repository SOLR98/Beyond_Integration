17 · 终端熔炼（批量烧炼网络物品）

把已绑定网络的便携终端放进熔炉“烧炼”，取出时一次性烧炼整个网络中所有可烧炼物品

功能概述

这是 bd_tweaks 中对 BD 终端的增强（默认关闭）：开启 furnace_terminal_smelt_all 后，把已绑定网络的便携终端（beyonddimensions:net_terminal_item）作为熔炉输入烧炼，取出产物（即同一个终端）时触发一次全网络批量熔炼：

  • 遍历网络统一存储中的全部物品键，逐条查询熔炉配方
  • 可烧炼的物品按配方转换为产物重新插入网络，原料被扣除
  • 烧炼产生的经验按 20 mB/点 折算为网络经验流体存入网络
  • 终端本身不消耗（配方产物 = 输入副本 + 一次性 NBT 标记），可重复使用
配方类型自定义配方序列化器注册名 beyond_integration:terminal_smelt（数据包 data/beyond_integration/recipes/terminal_smelt.json）。配方刻意继承原版 SmeltingRecipe，以规避 Mekanism 等模组对 RecipeType.SMELTING 的强制类型转换。

配置项

配置默认说明
bd_tweaks.xp_rod_enabledtrue经验棒修改总开关（与终端熔炼共用 bd_tweaks 分区）
bd_tweaks.furnace_terminal_smelt_allfalse熔炉烧网络终端触发批量熔炼
已知边界① 源码注释仍描述“由 AbstractFurnaceBlockEntityMixin 拦截、支持高炉/烟熏”，但当前实现只监听 RecipeType.SMELTING（普通熔炉）且不存在该 Mixin；② 返回的转换条目数为键条目数而非物品总数；③ 极大量物品同时烧炼时以“先插后扣 + 失败回滚”保证一致性，但网络被并发修改时统计的 used 可能与实际略有偏差。
