36 · 网络药水护符（Apotheosis）

把神化药水护符的效果经维度网络供应给玩家 / 女仆 · 各工程实现与差异（四格矩阵见 35）

它做什么

  • 神化（Apotheosis）的药水护符（PotionCharmItem）原本是放在饰品栏由玩家佩戴生效。 BI 让它们躺进维度网络也能生效：网络里所有启用（charm_enabled=true）且有药水效果的护符， 按配置间隔把效果施加给「把该网络设为主网络」的在线玩家 / 绑定该网络的女仆。
  • 效果按效果类型去重：同一药水效果只取最高等级；同等级优先「无法破坏」（不消耗），其次「自身经验修补」—— 避免低等级护符重复施加、重复扣经验。
  • 门槛：护符必须满足其一 —— 无法破坏、自身带经验修补、或该网络已献祭解锁经验修补。 无法破坏不消耗；其余每次施加扣网络 XP 流体（默认 1 XP = 20 mB）。
  • 与「原版护符」的消耗差异：饰品栏护符每次生效会磨损自身耐久（192 点，普通效果 -1、再生 -2，耗尽销毁）； BI 的泛化版不磨损护符，把代价换成网络 XP（Mending 门槛 + 每次扣费），护符本身永不损坏。

机制细节

环节行为落点 / 配置
结算频率 每 interval tick 对主网络玩家结算一次（默认 20 tick）；女仆由饰品 tick 驱动 potion_charm.interval；NetworkPotionCharmHandler.tick
生效目标（网络级） PLAYERS → MAIDS → BOTH → OFF 循环；存网络附件（NetworkAmmoData.potionCharmMode） feature/charm/PotionCharmMode；handler/PotionCharmAccessor + mixin/DimensionsNetMixin
效果与时长来源 神化药水护符的物品 NBT 记录一条药水效果（含持续时间）：PotionUtils.getMobEffects(stack) 取自护符编码的药水（或自定义 CustomPotionEffects），PotionCharmItem.getEffect 返回带 duration 的 MobEffectInstance。时长就是制作护符那瓶药水的时长（如 3600 tick）， 是护符本身携带、不是施加时才生成的 PotionCharmItem.hasEffect/getEffect（apotheosis 源码）； BI 侧读取：ApothCharmSupport.getEffect
刷新时机与施加时长 仅当目标身上的该效果剩余 ≤ refresh_lead_ticks（默认 10）才重新给予； 施加时长 = ceil(护符记录的 duration / 24) + refresh_lead_ticks， 再生效果额外加 50 >> amplifier tick 偏移。
原版护符（饰品栏）同样是 ceil(duration / 24) + criticalDuration， 但 criticalDuration 是固定规则（EXTENDED_POTIONS 命中 210，否则 5）， BI 用可配置的 refresh_lead_ticks 代替		 potion_charm.refresh_lead_ticks；NetworkPotionCharmHandler.applyCharm； 对照 PotionCharmItem#inventoryTick
经验消耗 无法破坏：免费；Mending（自身或献祭解锁）：每次扣 mending_xp_cost × 20 mB 的网络 XP 流体， 不足则本次不施加 potion_charm.mending_xp_cost（默认 1.0 XP → 20 mB）
献祭解锁 消耗网络内一本单条附魔=经验修补的附魔书 → 该网络持久化视为所有护符都有经验修补 NetworkPotionCharmHandler.sacrificeMending；状态存 NetworkAmmoData
同效果去重的口径 同一效果类型只留一件：先比增幅（amplifier），同级再比「无法破坏 > 自身经验修补」； 不比较 duration —— 同效果同等级时选中哪一件取决于网络扫描顺序，可能拿到时长较短的那件。 若要“取时长最长者”，需在 isBetter 里加 duration 比较 NetworkPotionCharmHandler.isBetter/potency
性能 护符状态按网络缓存（效果/增幅/时长/无法破坏/自身 Mending），并用 BdSubscriptionHub 订阅该网络存储 delta：只有护符相关物品增删才标记重扫，按网络去重，同一网络多名玩家只处理一次 NetworkPotionCharmHandler.NetRecord
网络销毁 / 关服 移除缓存与订阅（onNetDestroyed / clearCaches） 同上
