28 · BD 功能修改项

Beyond Integration 通过 Mixin 对主模组 Beyond Dimensions 目标类所作的行为修改与扩展汇总 · 基于 1.20.1-FORGE 与 1.21.1_NEOFORGE 的 beyond_integration.mixins.json 与源码归纳

说明

  • 本文只列对 BD 目标类（com.wintercogs.beyonddimensions.*）及为 BD 行为而动用的原版类的修改；对第三方模组（TACZ / SW / FTB / ywzj / 哨戒臂 / 女仆 / Thirst / JEI）的 Mixin 不在本文范围。
  • BI 不注册方块 / 物品 / 实体；对 BD 的接入分两类：（A）公开扩展点（插入拦截链、GUI 扩展注册表、补注册同名菜单等，见文档 26 与 22）；（B）Mixin 修改（本文）。
  • BD 类名以 1.20.1-Forge 分支为准，NeoForge 分支同名类位于相同包路径；差异在“双分支”列注明。

(A) 公开扩展点接入（非 Mixin）

接入点BD 类型BI 实现
插入前置拦截链UnifiedStorage 的 BeforeInsertHandler 扩展ItemBlacklistHandler / EnchantmentBookSeparatorHandler / AmmoBoxExtractHandler / SuperbAmmoInsertHandler
GUI 扩展注册表IDimensionsNetGUIExtension / BDGUIExtensionRegistryStorageMenuExtension / AmmoPanelExtension（隐藏/自动充电/物品保护/弹药面板/工作站模式按钮）
菜单类型补注册BD 终端「存储」菜单补充注册同名菜单类型并做界面扩展
网络订阅BD 存储订阅统一经 core/subscribe/BdSubscriptionHub 弱引用管理

(B) Mixin 修改清单（按 BD 功能归类）

1 · 网络核心（api.dimensionnet.DimensionsNet）

Mixin作用
DimensionsNetMixin为每个网络附加并持久化扩展数据：虚拟弹药计数（SuperbAmmoAccessor）、附魔分离开关（EnchantSeparationAccessor）、自动充能开关（EnergyChargeAccessor）、工作台激活状态（WorkstationActivationAccessor）、创造弹药计数（TaczCreativeAccessor）、网络名（NetworkNameProvider）。数据经 NetworkDataStore / NetworkAmmoData 统一读写

2 · 存储物品与交互

目标类Mixin作用
common.item.NetedItemNetedItemMixin联网物品的终端定位 / 保护等扩展行为
Item（原版，为 BD 联网物品）NetedItemClickMixin容器界面悬停左键双向快速存入 / 取出网络（悬停快速存储）
NetMagnetItemNetMagnetItemMixin · NetMagnetItemOpenMixin网络磁铁（物品）自定义档位：物品/流体分开、各自半径与执行间隔、独立节拍；界面入口重定向到 BI 复制界面
ItemStack（原版，Neo 专属）PlaceboCacheWriteDisableMixin禁用 Placebo 缓存写入，规避与 BD 数据附件/缓存的冲突

3 · 终端与合成界面

目标类Mixin作用
client.gui.DimensionsNetGUIDimensionsNetGUIMixin左侧按钮栏接管与重排（不依赖 BD LeftButtonSidebar）、左侧溢出列、RI 按钮屏蔽替代、JEI 避让 / 数量角标 / Shift 取物、行数最大值跟随、tooltip 层级
DimensionsCraftGUIDimensionsCraftGUIMixin合成台界面扩展（客户端）
DimensionsTerminalCraftGUIDimensionsTerminalCraftGUIMixin终端合成界面扩展（客户端）
common.menu.DimensionsCraftMenuBdBucketCraftTransferMixin桶 / 流体桶合成转换补料
common.menu.DimensionsCraftMenuTerminalBDMenuAccessor访问器：读取终端合成菜单内部字段
common.menu.widget.slot.AutoRefillResultSlotBdBucketAutoRefillMixin结果槽自动补充（桶/流体桶）
BD 桶/流体槽（类集合）BdBucketFluidSlotMixin流体槽与桶互转
integration.module.jei.transfer.TransferHelperBdBucketTransferHelperMixinBD 自带 JEI 配方转移的桶/流体补料适配
common.menu.DimensionsNetMenuBDMenuNetAccessor访问器：向外部（如哨戒机械臂假玩家）暴露网络引用

8 · 网络漏斗（方块磁铁）自定义档位

方块磁铁即 beyonddimensions:net_hopper_block（网络漏斗，物品/经验/流体都能吸）。BI 复用网络磁铁的档位配置（magnet.item_range_tiers / magnet.fluid_range_tiers），把物品/经验与流体分开处理，半径与执行间隔各自独立。

目标类Mixin作用
common.block.entity.NetHopperBlockEntityNetHopperBlockEntityTierMixin接管 getTicksPerWork / workStart / workContent：物品/经验用物品档位、流体用流体档位，半径与间隔各自独立；每方块选择存 NBT bi_hopper_tier_item / bi_hopper_tier_fluid
common.menu.NetHopperMenuNetHopperMenuTierMixin档位索引并入 BD 漏斗菜单的 QuickData 双向同步
client.gui.NetHopperGUINetHopperGUITierMixin（客户端）隐藏 BD 原“距离按钮”，新增 BI「物品档位 / 流体档位」两个按钮（档位名本地化）
