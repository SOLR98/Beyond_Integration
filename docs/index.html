0.7.0-dev 新增与变更

  • 维度网络通道过滤（11）：net_pathway 标记槽白名单（启用 / 仅接收输入 / 模糊），对外能力暴露裁剪；可配置标记槽行数。
  • 维度网络方块配置保留（11）：破坏保留配置 NBT（不含网络绑定）、手持对应物品 Shift+左键复制、8 个“自己合成自己”清 NBT 配方。
  • 网络图腾（06）：统一称呼（原“自动图腾 / 复活救援”），含基础触发与强化触发；消耗提示改为 HUD。
  • JEI 主网络会话同步（27）：bd_tweaks.primary_net_jei_sync 开启后任意界面按主网络显示数量角标与 Shift 取物。
  • Thirst 提纯（21）：网络熔炉按标记自动组装水瓶 / 水桶执行 Thirst 熔炼配方，可配熔炼速度。
  • Goety 联动（32，仅 1.20.1-FORGE）：把维度网络作为独立灵魂源（激活仪式 / 牢笼魂源 / 通道替代牢笼 / 击杀沉淀 / 网络复活与折扣 / HUD 第三条 / 原版仪式环境绕过）。
  • 通用 HUD 布局框架（33，仅客户端）：各 HUD 位置可自定义（相对/绝对），单界面同屏拖动编辑，统一配置 hud_layout。
  • 兼容性：移除对 BD LeftButtonSidebar 的依赖，兼容 BD 0.7.27 与 0.7.30。

功能关系网络

主模组 Beyond Dimensions、扩展本体 Beyond Integration 的功能模块与第三方依赖可视化关系图（可交互高亮）

快速了解

Beyond Integration 不注册任何方块/物品/实体；仅注册终端熔炼配方序列化器、口渴集成的 4 档纯净水流体（FluidType/Fluid，无方块/桶）与网络通道过滤菜单类型（net_pathway_filter），是纯跨模组桥接扩展。核心机制：

机制说明代表文件
插入拦截链物品进入网络前被拦截处理（黑名单、附魔分离、弹药折算）UnifiedStorageBeforeInsertHandler 4 个实现
Mixin 注入78（Forge）/ 75（NeoForge）个 Mixin 注入 TACZ/SW/哨戒臂/ywzj/BD/JEI/FTB，按模组加载条件启用（RI 加载时 JEI/FTB 集成让路）mixin/ 包 + MixinPlugin
网络数据包40（Forge）/ 41（NeoForge）个数据包，SW/TACZ 条件注册（Forge），主线程化处理network/PacketHandler
SavedData 持久化每网络虚拟弹药、附魔分离/充电开关、创造弹药计数NetworkAmmoData（经 NetworkDataStore 统一读写）
客户端缓存服务端轮询差分推送 → 客户端节流缓存 → HUD/界面渲染client/*Cache / client/*State
统一订阅BD 存储订阅统一经弱引用订阅中心管理，网络销毁/停服批量退订core/subscribe/BdSubscriptionHub

使用提示

  • 从 0.3.0 起，服务端与客户端都需要安装本模组。
  • 安装 Cloth Config API 可在游戏内修改配置（COMMON 与 CLIENT 两份文件；无 Cloth 时手动编辑 toml）。
  • 以任何方式把 SW 弹药 / 弹药盒存入网络都会自动折算为虚拟弹药（空箱保留）；TACZ 弹药盒入网自动拆箱（空盒保留）。
  • 网络接口方块可从网络弹药库提取实体弹药（提取映射见文档 13 配置）。
  • 网络相关功能需要对应网络权限：成员可访问存储，经理/所有者可切换附魔分离、自动充电等开关。
  • BD UI 框架变更预告：Beyond Dimensions 本体计划在下一版本更换 UI 框架；本模组所有依赖 BD 界面的代码（client/gui/**、DimensionsNetGUIMixin、DimensionsStorageMenu 等）已加提示注释，待 BD 正式发布后需统一校对坐标、纹理与按钮布局。
