06 · 载具绑定与网络充电（Superb Warfare）

SW 载具绑定维度网络、周期性抽取网络 FE 充电、HUD 信息显示

功能概述

玩家手持携带网络 ID 的物品（BD 网络终端 / 接入物品）右键 SW 载具即可完成绑定，此后：

  • 周期充电——每 N tick 从绑定网络的统一存储抽取能量（FE）给载具充电，支持固定速率 / 按缺失百分比两种模式
  • 网络弹药——载具武器射击优先消耗网络虚拟弹药（见文档 13）
  • HUD 显示——驾驶时左下角显示网络 ID、网络名、网络弹药、网络能量
  • 持久化——绑定关系写入载具 NBT（键 Net_id），弹药快照写入 BCE_AmmoList，重启不丢失
其他载具ywzj 载具的网络支持仅存在于 NeoForge 1.21.1 分支，见 文档 19；通用载具（非 SW）的绑定尝试经 VehicleInteractHandler 统一处理。
