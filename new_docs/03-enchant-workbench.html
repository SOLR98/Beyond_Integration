1. 附魔链路（三线共同的部分）

物品入网insert
附魔分离多附魔书 → 单附魔书 + XP 计费
同类同级合并单书合并到更高等级
批量附魔合并（仅工作台）
  • 前两步是入库规则（0.7.30 拦截式；0.8.x-1.20.1 计划式），三线都有。
  • 第三步是工作台交互（消耗附魔书与网络 XP，取高合并），0.8.x-1.20.1 缺失。
  • 计费：分离按配置公式（EnchantSeparateCommand 可调），XP 流体 1 点 = 20 mB。

2. 附魔分离的两种实现

工程实现要点
0.7.30·1.20.1 feature/enchant/EnchantmentBookSeparatorHandler 挂在 UnifiedStorageBeforeInsertHandler；命中后自行提取 XP、产出单书并写存储
0.7.30·1.21.1 同类逻辑，落点迁到 handler/EnchantmentBookSeparatorHandler（Neo 结构）
0.8.x·1.20.1 feature/enchant/EnchantmentBookSeparatorHandler 改为 InsertPlan：convert(1).take(XP).take(空白书).add(单书)； 同类同级合并“一次到位”（plan 内算可达最高等级，不再靠产出再入网级联）

3. 工作台体系的四种形态

0.7.30 · 1.20.1：自绘 7 合一 + 激活

  • GUI：client/gui/Dimensions{Craft,Anvil,Enchant,EnchantMerge,Grind,Smith,Stonecutter}GUI + Workstation{Render,Transfer}Helper / WorkstationModeConstants。
  • 菜单：feature/crafting/Dimensions*Menu + ICleanableWorkstation；NetworkCraftingHelper 负责“背包 + 网络”混合取料。
  • 激活：feature/workstation/WorkstationActivation + ActivateWorkstationPacket 等一套网络包 + /bdtools network … 命令。
  • 注入：DimensionsCraftGUIMixin、DimensionsTerminalCraftGUIMixin、BDBaseGUIRepairClickMixin 等。

0.7.30 · 1.21.1：同款，菜单搬到 init，多 Apoth 附魔台
