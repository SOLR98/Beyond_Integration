6. Mixin 体系

  • 四工程都用 beyond_integration.mixins.json：required=false、 refmap（0.7.30 与 0.8.x-1.20.1）、plugin 指向各自的 MixinPlugin（骨架工程除外）。
  • MixinPlugin.shouldApplyMixin 决定是否应用： 按目标模组是否加载（TACZ / SW / Goety / 铁魔法 / 小女仆 / JEI / RI / JEMI…）、 按版本探测（TACZ 1.1.4 vs 1.1.5+、taczaddon ≥1.1.8.1、JEI 15.56 布局）、 按类存在性（NetFeederMenu$1、NativeItemAtlas$Pages、XpExchangeScreenKt）。
  • 0.7.30-1.20.1 的 88 个 Mixin 里约 1/3 是 GUI/工作台注入；这批在 0.8.x 全部失效并删除 （0.8.x-1.20.1 只剩 69 个，且新增了 BdPage/图标兜底。
