1. 自动修复机制

  • 触发：XpExchangeItemMixin 在 BD XpExchangeItem.inventoryTick 的 TAIL 调用 XpAutoRepairHandler.onInventoryTick；只在服务端执行。
  • 门槛：配置总开关 xp_repair_enabled 打开 + 该经验棒 NBT 开关打开 + 绑定了网络。
  • 目标：只修带经验修补（Mending）且已损耗的物品；按范围收集并去重： 护甲四槽 / 背包 / 主手与副手 / Curios 饰品 / 女仆饰品槽（女仆场景）。
  • 档位：服务端配置 xp_repair_tiers = 名称:百分比:间隔（默认 low:5:20 / normal:10:10 / high:20:5 / max:50:1）； 物品 NBT 存档位索引；interval > 1 时按 player.tickCount % interval 限频。
  • 修复量：修复模式 xp_repair_mode： PERCENT（每次修最大耐久的百分比）或 ABSOLUTE（固定 xp_repair_absolute 点）。
  • 计费：每 1 点网络经验修 2 点耐久；经验取自网络 XP 流体（1 XP = 20 mB），批量提取、用不完回插。

4. 给予方式（BATCH / DIRECT）

  • xp_rod.grant_mode（默认 BATCH）：
  • BATCH：BD 原逻辑分批 giveExperiencePoints（BI 已把上限放宽到 238609312）； xp_rod.grant_batch_size 控制每批大小。
  • DIRECT：XpDirectGranter 在 keepXpLevel HEAD 接管——等级计算 + 直接设定 + 经验补差； XpGrantHelper 提供共用的等级/经验换算。
  • 0.8.x-1.20.1 的页面只显示当前方式（服务端配置，玩家不可改）。

5. 女仆饰品

  • maid/XpExchangeBauble implements IMaidBauble：经验棒放进女仆饰品槽后由 TLM 每 tick 调用 onTick。
  • collectTargets 读女仆的装备 / 女仆背包 / 主手副手 / Curios / 女仆饰品槽； 最后一个由 XpRepairSettings.isMaidEnabled 控制（页面文案“女仆饰品”）。
  • TLM 的 MAID_MENDING_BLOCKLIST_ITEM 标签内的物品会被跳过。
  • 女仆还会维持经验棒的目标等级（keepMaidXpLevel，120 XP/级）。
