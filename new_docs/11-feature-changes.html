11 · 功能变动说明

基准：beyond_integration-1.20.1-forge-0.8.0-beta.jar（0.8.0-beta，2026-10-28 构建）。 对比对象：当前 NEW_FORGE_1.20.1 与 NEW_NEOFORGE_1.21.1 源码。 本篇只讲功能与行为（玩家 / 服主 / 整合包作者视角），类与方法级清单见 10 · 代码差异。描述以当前源码实际实现为准，未实测项标 ?。

2. 新增功能

2.1 附魔台（工作台）

  • 入口在 BD 存储界面的工作台页（EnchantTableWorkbench.kt / EnchantTableMenu）， 放入装备后显示三档附魔结果，可悬停查看“前置等级 / 消耗等级 / 青金石 / 经验点数”。
  • 支持刷新结果（可配置刷新是否消耗青金石）、关闭预览、附魔分离（消耗经验与空白书，从装备分出附魔书）。
  • 服务端可调：功率模式与固定功率、经验/等级换算、无视“已附魔”、无视附魔冲突、免青金石或自动从网络补青金石、 解除前置等级门槛（改为按经验点计费）、解除功率上限、费用百分比、允许宝藏附魔、过滤附魔列表、分离总开关。
  • “无视冲突”“解除等级门槛”等原先只能在铁砧配置里调整的放宽项，现在是附魔台自己的配置项。

2.2 神化附魔台（Apotheosis 模式）

  • 同一工作台的第二种模式：显示并调整 Eterna / Quanta / Arcana / Rectification 四项属性，附“上限”显示。
  • 书架扫描：读取网络存档的书架属性；可配置“是否需要献祭书架来提升上限”“是否忽略书架自身的最高值” 以及四项属性的硬上限（0–100，默认 100 即不额外限制）。
  • 献祭：手持书架点击献祭，按书架能提供的属性提升上限；四项全满或该书架无贡献时会提示不可献祭。
  • 另支持书架附魔过滤（读到的黑名单可添加/移除）、宝藏附魔可用状态提示、献祭预览与失败原因提示。

2.3 附魔合并

  • 在界面中选择网络里的装备，列出“可升级附魔”及 当前 → 目标 等级与总费用，消耗网络 XP 与对应附魔书完成合并。
  • 拆分高等级书需要普通书；网络 XP 不足、缺书、无可变化时会给出对应提示。
  • 受网络设置里的“附魔分离”影响（入网多附魔书先拆成单书）。
  • ? 该界面目前是整页页签，配置注释里保留了“待 BD 提供存储界面右栏扩展 API 后改为右侧扩展”的说明。

2.4 网络设置页

  • 挂在 BD 存储界面上的 BI 设置页，只作用于当前打开的网络；修改需要网络经理或所有者权限。
  • 可切换：附魔分离（入网多附魔书自动拆单书，消耗网络 XP）、自动充电（盔甲/手持/Curios/女仆饰品从网络 FE 充电）、 网络药水护符的生效目标（点击循环）、经验修补献祭（消耗网络内一本“单条附魔 = 经验修补”的书，永久解锁该网络门槛）。
  • 没有可用网络（不在网络终端/存储界面且主网络未同步）时会提示无法读取或修改。

2.5 女仆 P 点（Touhou Little Maid）

  • 总开关默认关闭；开启后：女仆拾取 P 点时存入网络（默认开）、玩家 P 点从网络自动回填（默认关， 间隔 20 tick、单次最多 1.0 P，均可配）。
  • TLM 祭坛合成时本地 P 点不足的差额自动从网络扣，P 点不会额外停在玩家身上。

2.6 TACZ：合成、配件、弹药、TUD

  • 枪械台合成：网络材料模式下，材料先扣背包再扣网络，消耗前先 simulate 预检，产物可入网络或掉落 （客户端配置：tacz_smith_use_network 默认开、tacz_smith_output_to_network 默认关）。 与 taczaddon 的合成按钮包装做兼容，网络模式不再“点击无反应”。
  • 网络配件：改装界面新增网络配件槽，可从网络安装配件（换下的旧配件写回网络，失败退背包再失败掉落）、 也可把枪上配件拆回网络（先预检，失败不卸）。
  • 弹药：推送改为按玩家背包裁剪的增量快照（0 值删除），可只请求指定弹药；统计与消耗会计入女仆背包； 支持主网络镜像供多客户端共享。
  • TUD：仅 TUD 环境生效，服务端遍历枪械索引构建“枪 → 弹药”映射并下发，客户端无需本地 TUD 配置。
  • 命令侧新增“整批插入弹药 / 配件”的子命令（具体语法见 NetworkInsertCommand）。

2.7 其他新增

  • JEI：客户端总开关 jei_integration（默认开）；关闭后本模组不再介入 JEI。
  • 水纯度：带 Purity 标签的原版水入网时按 1:1 转成 BI 的 4 档水 （dirty / slightly_dirty / acceptable / purified），无标签的原版水保持原样；拆桶会补纯度；旧存档数据自动迁移。
  • 铁魔法：持续施法的中断判定改用“本地蓝 + 网络魔力”，网络蓝充足时不再被误判中断，扣费仍走网络。
  • 经验棒：新增“女仆修复时忽略 TLM 经验修补黑名单”开关（默认关）。
  • 调试：组件预览、排版与布局预览两个调试页。

3. 移除 / 回退

功能影响
网络磁铁物品/流体吸附、tier 范围配置与对应 Mixin 全部消失；CommandConfig 里的 3 个 magnet 配置字段仍在注册，但已无实现读取（死配置）
漏斗 tierNet 漏斗分级逻辑与 Mixin 删除，漏斗回到基线行为；两分支只剩空目录 feature/hopper
工作台献祭激活“未激活点击 = 献祭”与激活成本配置删除；工作台可用性不再由配置列表控制
Refined Storage 补丁自动进食按钮接管、侧栏修复、容器传输修复等 5 个客户端 Mixin 全删；RsIntegrationCompat 仍保留但不再注入
铁砧放宽配置（anvil.*）等级上限突破、无视冲突/适用性、罚金与百分比等 14 项删除；同类能力改到附魔台（enchant_table.*）
附魔分离“最大重入次数”配置删除，改为附魔台内的分离总开关
合成冷却 / 最大深度配置craft.* 删除（当前源码无对应新键）

4. 已有功能的行为变化

功能变化
TACZ 弹药同步推送包新增 partial 标记并进入编码（编码顺序 netId, netName, partial, size, (id,count)*）； 请求包可携带弹药 ID 列表；跨版本联机不兼容
枪械 HUD渲染逻辑重写（旧版缓存计数/背包弹药回调不复存在），显示以新缓存为准
护符 / 回蓝 / 充电由全局 tick 事件遍历玩家改为 BD 网络 tick 任务：同一网络只调度一次，主网络之外不再处理；护符记录按网络缓存
网络通道过滤改为包装 BD 能力视图工厂（NetPathwayCapabilityWrapper），不再依赖方块实体的能力注入点
终端通道过滤存储内部结构重构（NetPathwayFilteredStorage 去掉旧的键/桶结构），对外行为不变
附魔分离规则层逻辑与 jar 一致；新增附魔台内开关；原“拦截链最大重入次数”配置不再读取
主网同步新增外部缓存变更检测（ExtCache），外部操作后更快刷新
HUD 文案英文 Net: INF ammo → Net: infinity ammo（中文仍为“网络: ∞”）
配置界面铁砧、工作台两个分类消失；新增附魔台、神化附魔台、女仆 P 点等分类与“隐藏（未完成）”提示的移除

5. 配置变动与迁移

类型键处理建议
删除（失效）anvil.*（14）、workstation.*（5）、craft.*（2）、 enchantment_separation.max_reentrancy、hidden.apoth 升级后旧 beyond_integration-server.toml 里的这些键会被忽略，可手动删掉； 原来靠 anvil.* 放宽的行为改到 enchant_table.* 配
新增（默认值）enchant_table.*（含 apothic.*）、maid_power.* （enabled=false / pickup=true / auto_refill=false / interval=20 / max_points=1.0）、 bd_tweaks.xp_repair_ignore_maid_blacklist（false） 按需开启；女仆 P 点默认关闭，需服主显式打开
客户端新增enchant_level_roman、jei_integration、show_net_sync_status、 enchant_merge_rows默认值可用；JEI 关闭后本模组完全不介入 JEI
残留（待确认）magnet_custom_tiers_enabled、magnet_item_range_tiers、 magnet_fluid_range_tiers? 无实现读取，属死配置；确认删字段还是恢复功能

6. 升级与兼容

  • 联机必须同版本：TACZ 弹药推送/请求协议已变（新增 partial 与弹药 ID 列表），旧客户端连新服（或反之）会解析错位； 新增的 12 个网络包旧端也不存在。
  • 配置：旧键失效见第 5 节；新增键不配也能跑（默认值已给出）。
  • 资源：data/ 与 assets/ 除语言文件外与 jar 字节一致，配方/标签/规则没有结构变化。
  • 依赖：mods.toml 依赖范围与原包一致（BD ≥ 0.8.3、可选 AE2LT ≥ 1.0.2）； 附魔台/神化相关功能依赖对应联动模组存在（Apotheosis、Iron's Spells、TLM、TACZ、TUD、Thirst 等）。
  • 功能回退：使用网络磁铁/漏斗 tier 的整合包需要另找方案或等待功能恢复；RS 用户不再享受本模组的界面补丁。
  • 1.21.1：功能集与 1.20.1 相同，差异只在 MC/loader API 与版本专用 Mixin（详见 10 · 代码差异）。
