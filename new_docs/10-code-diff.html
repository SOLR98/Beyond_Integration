10 · 代码差异：0.8.0-beta 构建包 → 当前源码

对比 beyond_integration-1.20.1-forge-0.8.0-beta.jar（mods.toml version = "0.8.0-beta"， Implementation-Timestamp 2026-10-28）与当前 NEW_FORGE_1.20.1（mod_version=0.8.0-beta）、 NEW_NEOFORGE_1.21.1（mod_version=0.8.1-beta）源码。 按 计划项目/已完成/2026-11-02-NEW_NEOFORGE全量移植NEW_FORGE.md，1.21.1 已移植 1.20.1 的功能， 本文的「增/删/改」对两者同时成立，仅 1.21.1 特有的 Mixin 与 API 适配不同。

7. 构建与兼容性

  • jar 的 MANIFEST.MF：Implementation-Title: new_forge_1-20-1、Implementation-Version: 0.8.0-beta、 MixinConfigs: beyond_integration.mixins.json；源码 MANIFEST.MF 为 68 字节占位，由 gradle 生成。
  • 协议层：TaczAmmoPushS2CPacket 等 3 个包编码变化，跨版本联机不兼容；新加的 12 个包在旧端不存在。
  • Mixin 层：依赖 RS 的 5 个补丁被移除后，RsIntegrationCompat 仍保留但不再注入；磁铁/漏斗 tier 移除后相关网络存储行为回到基线。
  • 配置层：删除的 anvil.* / workstations.* / craft.* 键在升级后失效；新增的 enchant_table.* / maid_power.* 需重新配置（默认值可跑）。
  • 资源层：data/ 无变化，说明 BD 规则注册、配方、标签等未受影响。
