1. TACZ 网络供弹

  • 取弹：TaczAmmoExtractor 从网络按弹药键提取；`AmmoConsumerMixin`（玩家/女仆/载具）在消耗点时接管。 0.7.30-1.21.1 另有 TaczCreativeAccessor/TaczEventHandler（创造模式与事件桥）。
  • 计数与推送：TaczAmmoTracker + TaczAmmoPollingService（轮询网络差分， 只在变化时推 TaczAmmoPushS2CPacket）；客户端 TaczAmmoCache/TaczAmmoMirror 缓存。
  • 弹药箱/弹药库：AmmoBoxExtractHandler（盒装 → 子弹 + 空盒）、 AmmoStorageExtractHandler（弹药库方块 → 各条目弹药 + 空方块）。 0.8.x-1.20.1 都改写为 InsertPlan.convert(1).add(…)。
  • 配方索引：TaczRecipeIndex + Client/Server Events（枪械台网络合成用）； 0.8.x-1.20.1 保留索引类但工作台已删（无消费方，见 03 篇）。

2. SW 弹药（两条口径不能混用）

工程存储口径关键类迁移
0.7.30·1.20.1 虚拟计数：NetworkAmmoData.networkAmmo = Map<弹药类型, 发数> SuperbAmmoInsertHandler（盒装折算）、SwAmmoTracker、SwAmmoPollingService —
0.7.30·1.21.1 虚拟计数（同上） handler/SuperbAmmoInsertHandler、SuperbAmmoAccessor、SwAmmoPollingService —
0.8.x·1.20.1 散装弹药物品（superbwarfare:*_ammo，1 个 = 1 发） SwAmmoStorage（物品键口径的 count/consume/hasInfinite/snapshot）、 SuperbAmmoInsertHandler（盒装 → 散装转化规则） SwAmmoMigration：ServerStartedEvent 时按旧 NetworkAmmoData 逐网络迁移；__infinite__ → 创造弹药箱物品
协议兼容 0.8.x 的 HUD / 载具报文仍按“弹药类型 → 发数”输出（snapshot 由物品键折算）， 所以下游协议不变；但存档层面虚拟计数已不存在，跨分支回退需要 SwAmmoMigration 的反向迁移（未实现）。

3. 能量充能（含 0.8.x 的入口缺口）

  • 逻辑：EnergyAmmoChargeHandler（0.7.30-1.20.1 在 feature/ammo/sw， 1.21.1 在 handler）按网络 FE 给盔甲 / 手持 / Curios / 女仆饰物 充电。
  • 网络级开关：EnchantSeparationState 的同类——client/EnergyChargeState + 三包 Toggle/Request/Sync EnergyChargePacket + handler/EnergyChargeAccessor。
  • 入口：0.7.30 两线是 BD 网络界面按钮 client/widget/EnergyChargeToggleBtn（由 GUI Mixin 挂上）。
  • 0.8.x-1.20.1：client/widget/EnergyChargeToggleBtn 不存在， ToggleEnergyChargePacket 仅出现在注册表里（PacketHandler 与自身定义）， 也没有对应命令。现已补齐：新增的「网络设置」页（按当前打开的存储界面所连网络读写，DimensionsNetMenu.networkId() + 服务端 NetMenuResolver） （client/page/NetSettingsPage.kt，注入 BD NetControlMenu）提供该开关的图形入口。
  • 附魔分离属于同类开关，原本保留命令入口 /bdtools enchant separate，现在也在「网络设置」页里。
